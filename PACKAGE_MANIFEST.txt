Infinite-Turbo (for Windows) - source package
Version: 0.32.0-turbo (base: Windows R31a port)
Upstream: https://github.com/n1m21n/Infinite
Upstream commit: 788404af4b378941394e2d5dcc45c5542cc903fd
Target: Windows 10/11 x64 only, Visual Studio 2022 (MSVC), vcpkg x64-windows-static
Enabled by default: VST3 (JUCE), MIDI/WASAPI, Spout2, OpenCV video/camera/DNN, Assimp, FFmpeg mux, Windows ML + DirectML matting, AVX2
Fallback: OpenCV DNN CPU for Remove Background

Entry points:
- install-dependencies.bat   first-time dev setup (UAC)
- build-windows.bat          [debug] [fresh] [nopack]
- run-windows.bat
- install-runtime.bat        for prebuilt ZIP users
- diagnose-windows.bat
- WINDOWS_BUILD.md, CHANGELOG-TURBO.md

macOS sources (Objective-C++ platform layer, Syphon, Steinberg VST3 SDK
submodule, app bundle resources, DMG tooling, website) were removed in 0.32.

Bundled UI font:
- assets/fonts/IBMPlexSans-Regular.ttf
- assets/fonts/OFL.txt
