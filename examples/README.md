# Infinite-Turbo examples

Patches made with Infinite-Turbo, shipped with every release and copied next to
the app by the build (`<app folder>/examples`). They show up in **FILE > Examples**
and open as untitled documents, so Save As keeps your own version and the
example stays as it was.

Adding one (from 0.59 on): put the `.inf` here, with any media it uses in a
subfolder of the same name (`examples/my-patch/clip.mp4`) and paths relative to
the patch. Name files the way they should read in the menu (`OCO - live set.inf`).
Only material we made or that is free to redistribute goes in this folder.

---

Exemplos de patches feitos com o Infinite-Turbo. Vão junto com cada release e o
build copia a pasta para o lado do app. Aparecem em **FILE > Examples** e abrem
sem título (o Save As guarda a sua versão, o exemplo fica intacto). Para incluir
um: coloque o `.inf` aqui, com a mídia numa subpasta de mesmo nome.
