One-command AI agent setup

Connect Infinite's nine MCP tools to Claude Desktop, Cursor and Windsurf with one terminal command:

npx -y infinite-engine init

For Python environments, run pip install infinite-daw.

Teach Cursor and Windsurf your syntax

Place a .cursorrules or .windsurfrules file in your workspace to teach any coding assistant the seven Tongue verbs (ask, add, set, wire, cut, del, field) and zero-sigil Field language rules:

# Tongue v0: write a patch as declarative sentences
add Shape as s
set s.shapeType Circle
add gaussianblur as blur
set blur.uRadius 8
wire s blur.in
wire blur out.in

# Field: per-sample DSP with bare names (zero sigils)
field synth state float p = 0; p = (p + freq / sr) % 1.0; out = sin(6.28318 * p) * gate * 0.3;

The full grammar and node reference are documented in llms.txt and the Field manual (PDF).

The nine MCP tools

infinite_synthesize_field_synthSynthesise WAV audio from an inline Field Synth kernel
infinite_synthesize_field_notesAlgorithmic notes and Euclidean rhythms from a Field Notes kernel, rendered to audio
infinite_process_field_effectRun audio through an inline Field Effect kernel, such as a filter or wavefolder

infinite_render_field_modifierDeform a mesh with an inline Field Modifier kernel
infinite_render_sketch3dRender JavaScript-built 3D geometry to a PNG
infinite_validate_patchCheck a .inf patch against the engine and report every problem
infinite_render_videoRender an MP4 from a .inf patch, headless

What you need

  • The Infinite app installed. The SDK and the MCP server find it through the INFINITE_BIN environment variable, /Applications/Infinite.app, a build folder in the checkout, or your PATH. On Windows and Linux, set INFINITE_BIN to the path of Infinite.exe or Infinite.
  • Python 3.8 or newer: pip install infinite-daw. Nothing else to install: the SDK has zero third-party dependencies.
  • Node 18 or newer: npx -y infinite-engine init.
  • Hardware inputs, such as a microphone or camera, are refused in headless mode.
