# Website design system v3

How infinitedevices.org applies the brand book (BRAND.md). One rule set for every page. Each value lives once, in `brand.json`; the tools check the rest.

**Taste in one line:** a programme, not a layout (BRAND.md section 16, after Arte Programmata and Karl Gerstner). Sizes are rules with variables, every page has one thing to touch, and what the page shows is the real product.

Live specimen: `website/system.html` (noindex). Open it at phone and desktop width before changing a component.

## Layers

| Layer | File | Holds | Edit? |
|---|---|---|---|
| Brand tokens | `website/brand.css` | Colour roles per mode, `--type-*`, `--size-*`, numerals, `--web-*` device programme, `--z-*`, motion | Generated by `tools/brand/build_brand_book.py` from `docs/brand/brand.json` |
| Site aliases and base | `website/style.css` | `--fs-*`, `--r-*`, `--gutter` aliased onto brand tokens; header, buttons, base elements | Yes; never a raw hex or size in `:root` |
| Primitives | `website/system.css` | Containers, sticky footer, type classes, numerals, controls and hit areas, chips, dropdowns, cards, reels, lite video, programmed field, kinetic type, focus | Yes |
| Page sheets | `artists.css`, `blog.css`, `reels.css`, ... | Page layouts | Yes, with tokens only (`token_lint.py`) |
| Device scale | `website/scale.css` | Per-device control and type overrides, the 12 px floor | Yes |
| Behaviour | `kinetic.js`, `field.js`, `theme.js`, `site.js` | Kinetic type and numerals, programmed field, mode, dock | Yes |

`tools/website/sync_chrome.py` puts `system.css` then `scale.css` last in every page head (hash-versioned), and keeps the header, dock and footer identical.

## Taste rules

1. One idea per section: a folio (`02 / numerals`), a title, at most one Caveat word in Ember, a lead of 30 words or fewer, then the thing itself.
2. Show the real product: app screenshots, live shaders, real node names and measured figures. No stock images, device mockups or invented numbers.
3. One Ember per frame, under 10% of its area. Signal is for structure and focus, never a button fill.
4. One primary button per frame. Everything else is a quiet pill.
5. Space is generous and on the 4 px grid; density comes from the content, not from shrinking gaps.
6. Motion answers a touch within a 1/16 note (125 ms) and settles on a spring. Nothing loops on text people read.
7. No outlines, no borders around cards, no chrome blobs, no neon, no moiré.
8. Copy is plain, British, in sentence case, with no em dashes and no hype.

## Device programme

Each token is `[phone, desktop]`. Space interpolates from 375 to 1440 px and snaps to 4 px; controls and radii step at 640 px.

| Token | Phone | Desktop | Use |
|---|---|---|---|
| `--web-margin` | 16 | 48 | Page side margin (`--gutter`) |
| `--web-gutter` | 16 | 24 | Gap between grid items |
| `--web-section` | 64 | 96 | Section padding top and bottom |
| `--web-section-tight` | 48 | 64 | Sections that continue the previous one |
| `--web-card-pad` / `-lg` | 20 / 24 | 24 / 32 | Card padding |
| `--web-card-radius` | 20 | 24 | Every card |
| `--web-media-radius` | 12 | 16 | Media inside a card, video posters |
| `--web-stack-s/m/l/xl` | 8 / 12 / 16 / 24 | 8 / 16 / 24 / 32 | Vertical rhythm inside a block |
| `--web-control` | 36 | 40 | Pills: chips that act, tabs, segmented controls, copy |
| `--web-button` / `-lg` | 40 / 48 | 44 / 52 | Buttons; large for the one Download per page |
| `--web-hit` | 44 | 40 | Invisible touch target (44 on any coarse pointer) |
| `--web-icon` / `-nav` / `-inline` | 18 / 20 / 16 | 20 / 24 / 16 | Glyphs in controls, the dock, running text |
| `--web-header` | 56 | 60 | Top bar |
| `--web-dock` | 64 | 56 | Bottom bar (phone) or rail width (desktop) |
| `--web-max` | 1200 | 1200 | Content width |
| `--web-measure` | 34em | 34em | Body text line length: 68 characters of Geist (about 0.5em each) |

Breakpoints: phone up to 640, tablet 641 to 1024, desktop 1025 and up, wide 1441 and up. The dock switches from a bottom bar to a left rail at 901.

**Containers.** `.container` is `--wrap` (default `--web-max`) plus side padding. On desktop the padding grows only as far as needed to clear the rail (16 + 56 + 16 px) on both sides, so every column stays centred. Narrower columns set `--wrap` (blog posts 688, benchmarks 960, footer 1040); never `max-width` or one-sided padding.

## Typography

Families: Geist for reading, Geist Mono for values, code, node types and folios, Caveat for one human word per section. Pixel 5x7 only when the machine speaks.

| Step | Phone | Desktop | Weight / leading | Class | Token |
|---|---|---|---|---|---|
| Display | 40 | 96 | 800 / 0.98 | `.t-display` | `--type-display`, `--size-display` |
| H1 | 32 | 61 | 750 / 1.04 | `.t-h1` | `--type-h1` |
| H2 | 25 | 39 | 700 / 1.1 | `.t-h2` | `--type-h2` |
| H3 | 20 | 25 | 650 / 1.2 | `.t-h3`, `.card-title` | `--type-h3` |
| Lead | 18 | 20 | 450 / 1.45 | `.t-lead` | `--type-lead` |
| Body | 16 | 16 | 400 / 1.55 | `.t-body` | `--type-body` |
| Caption | 13.5 | 13.5 | 500 / 1.45 | `.t-caption` | `--type-caption` |
| Micro mono | 12 | 12 | 500 / 1.35 | `.t-micro` | `--type-micro-mono` |
| Folio mono caps | 12 | 12 | 500 / 1.2, +0.12 em | `.folio` | `--type-folio-mono-caps` |

- **Floor:** nothing a visitor reads is under 12 px (`--web-floor`). `scale.css` enforces it for legacy selectors; `ui_type.mjs` and the hygiene suite fail below it.
- **Tracking:** use `--track-*` with its step. Display and H1 are tight (-0.04, -0.035 em); mono labels open up (+0.04 em, caps +0.12 em).
- **Measure:** body text 60 to 72 characters, captions 30 to 45, leads up to 30 words. Headlines use `text-wrap: balance`, body `pretty`.
- **Font sizes in CSS** are `var(--size-*)` or `var(--fs-*)`; `token_lint.py` counts raw values and may not rise.

### Numerals

| Step | Phone | Desktop | Class |
|---|---|---|---|
| Num XL | 64 | 160 | `.fig.fig-xl` (one hero figure per page) |
| Num L | 40 | 72 | `.fig.fig-l` (stat tiles, 2 to 4 in a `.stat-row`) |
| Num M | 28 | 40 | `.fig.fig-m` (inside cards and tables) |

`<span class="fig fig-l" data-count="120">120<span class="fig-unit">BPM</span></span>`: Geist 800, tabular lining figures, tracking -0.05 em; the unit in mono at a quarter size, top-aligned, ink-3, never under 12 px. `data-count` counts up once on first view (667 ms). Pairs use `.ratio-sep`. Folios and card indexes are two-digit mono (`01`), never Ember.

### Kinetic and curved type (`kinetic.js`)

| Move | Markup | Rule |
|---|---|---|
| Slab-in | `.kt-slab` | Words rise once on the slab spring, 42 ms apart; the heading keeps its full text as `aria-label` |
| Draw | `.kt-draw` | The Caveat word's hand underline draws once, 500 ms |
| Swap | `.kt-swap data-words="a,b,c"` | One word every 2 bars (4 s); pauses when the tab is hidden; one per page |
| Count | `data-count` | Once, first view |
| Loop | `svg.loop-type` with a `textPath` | Mono caps on a circle or the lemniscate, one lap per 16 s, aria-hidden, words repeated as real text, one per page |

Never: infinite motion on text people read (the typewriter on the home page is a known exception to remove), more than 15 characters a second, scroll-jacked type, blur-in body copy. Reduced motion: everything in its final state.

## Controls

| Control | Phone | Desktop | Shape | Class |
|---|---|---|---|---|
| Button | 40 tall, 20 side padding | 44, 20 | Pill | `.btn`, `.sys-btn` |
| Large button | 48 | 52 | Pill | `.btn-lg`, `.sys-btn.lg` (Download only) |
| Pill control | 36, 12 side padding, 13 px | 40, 16, 13.5 px | Pill | `.sys-ctl`, `.pill`, tabs, `.copy` |
| Icon button | 36 square (44 hit) | 40 square | Circle | `.sys-ctl.icon-only`, `.icon-btn` |
| Chip (label, not a button) | 28 | 28 | Radius 10 | `.sys-chip` |
| Text input | 40 | 44 | Pill | `.signup-row input` |

- **Hit area:** every control has an invisible `::after` of at least 44 px on touch (`--web-hit`), so a 36 px pill is still easy to tap. Pills in a row keep 8 px between them.
- **States:** hover lifts 1 px (pointer only); press scales to 0.96 on the press spring; on/current is ink fill with ground text; disabled is 40% opacity with no hover. Focus is a 2 px Signal ring, 3 px offset, on every interactive element.
- **One primary per frame.** Primary is ink fill; secondary is surface-2 with a soft shadow; never two filled buttons side by side.
- **Labels:** one verb, sentence case, one line (Download Infinite, Copy code, Full screen). A glyph may sit left of the label at `--web-icon`; then the left padding is 4 px less than the right (12 and 16), so the pill looks even.

### Dropdowns

| | Phone | Desktop |
|---|---|---|
| Trigger | `.sys-ctl` with a chevron, `aria-haspopup`, `aria-expanded` | same |
| List | Bottom sheet, 12 px from the edges, max 70% of the height, options 44 tall | Popover 8 px under the trigger, at least 220 wide, options 40 tall |
| Motion | Rises 16 px, 188 ms ease-out | Fades and drops 4 px, 188 ms |
| Keys | Escape closes and returns focus to the trigger; arrows move; Enter picks | same |

Markup: `.sys-pop > button + [role=listbox]`. Native `<select>` stays native where the choice is a plain form value. Lists never clip: `ui_audit.mjs` fails a dropdown that leaves the screen.

## Navigation

| Part | Phone (up to 900) | Desktop (901 and up) |
|---|---|---|
| Header | 56 tall, logo left, mode toggle and socials right, sticky, glass | 60 tall, adds GitHub and a small Download |
| Dock | Bottom bar, 12 px from the edges and the safe area, four stops (Home, For you, Explore, Learn) with glyph over label | Left rail at 16 px, vertically centred, 56 wide icon column that opens to labels on hover, focus or tap |
| Group sheet | Slides up above the bar, full width | Opens beside the rail, 260 wide |
| Current page | Filled pill in the sheet, `aria-current` | same |
| Footer | Stacks: sign-up, link columns, socials, sign-off | Columns in a 1040 wrap |

- **Sticky footer:** `body` is a column flex box at least one screen tall; `main` grows, so the footer always sits at the bottom on short pages.
- **Clearance:** phones pad the page bottom by the dock height (88 px) so the last control is never under the bar; desktop containers clear the rail (see Containers).
- Download lives in the page content (hero or CTA), not in the dock.

## Cards (library, blog, embeds)

Anatomy, top to bottom: media (16:10, inset, `--web-media-radius`), folio and chips, title (H3, two lines at most), one sentence (two lines at most), foot (meta left in micro mono, one action pill right). The whole card is one link (`.card-link::after`), so it has one tab stop.

| | Phone | Tablet | Desktop | Wide |
|---|---|---|---|---|
| Columns | 1 | 2 | 3 | 4 (library) |
| Padding | 20 | 24 | 24 | 24 |
| Radius | 20 | 24 | 24 | 24 |
| Gap | 16 | 20 | 24 | 24 |

- Surface-1, `--shadow-1`, no outline; hover lifts 2 px to `--shadow-2` on the soft spring (pointer only).
- Card pictures: the category colour (`--cat`) gradient over a dark base, the picture framed inside it, never baked or cropped to a poster. Sources at least 720 wide, 16:10, no text baked in. Titles sit on a glass bar at the foot in the bento view.
- Library: label above, preview, one sentence, price pill left, action pill right. Blog: category chip, title, date and reading time. Embeds: the live widget, Copy code and Full screen pills.

## Reels and video

| | Phone | Desktop |
|---|---|---|
| Reel card | 9:16, 70% of the width (about 260 px) with a 15% peek of the next | 300 px wide, as many as fit, scroll with arrow keys or the trackpad |
| Snap | One card at a time (`scroll-snap-type: x mandatory`) | same |
| Video | 16:9 poster with a 64 px play button; the player loads on tap from youtube-nocookie | same |
| Full-screen reel (`embeds/`) | Vertical swipe, one slide per screen, rail of actions on the right | Centred 9:16 stage, rail beside it |

Primitives: `.reel-track` for sideways rows, `.lite-yt` (or the existing `.yt-embed`) for video. Shaders run only while visible, pause under reduced motion and show a still frame. A page stays under 1.8 MB before the optional 3D viewer loads.

## Modes

Midnight (show) is the default. Paper (read) for long-form pages (philosophy, blog posts) via `window.INFINITE_DEFAULT_MODE`. The header toggle switches and remembers (`localStorage infinite-mode`). Mist is for diagrams inside a page. Every component uses roles (`--ground`, `--surface-1`, `--ink`, `--signal`, `--accent`), so it works in every mode without a per-mode rule.

## The programmed field

The brand signature: `.pfield` with `field.js`. A grid of unit marks chosen and sized by a seeded signal and the pointer, Signal colour with one Ember cell, stepping on the beat. `data-strength="0.06"` for texture behind text, `1` for one hero field per page, masked so text sits on clear ground. Static under reduced motion; paused offscreen and in hidden tabs.

## SEO and linking

| Rule | Checked by |
|---|---|
| Title 30 to 60 characters, description 70 to 160, one h1, no skipped heading levels | `tools/seo/site_audit.py` |
| Canonical to the page itself; og:title, og:description, og:image; `lang` | `site_audit.py` |
| JSON-LD that parses: SoftwareApplication on home, BlogPosting on posts, CreativeWork on library and embeds, FAQPage where there is a FAQ | `site_audit.py`, `tools/seo/check.py` (blog) |
| Alt text on every image; width and height on every image | `site_audit.py`, hygiene `img-no-dimensions` |
| No broken internal links or anchors | `site_audit.py` |
| Every indexable page has at least 3 inlinks from other pages; no orphans | `site_audit.py` (`--links PAGE` shows the graph) |
| `sitemap.xml` lists every indexable page and nothing else | `site_audit.py`; the sitemap is written by `tools/website/gen_seo.py` |
| Unfinished or private pages carry `noindex` and stay out of the sitemap | `site_audit.py` |

Interlinking pattern: audience pages link to their library templates, blog posts and embeds; blog posts end with three related cards; library and embed pages link to the matching blog post and audience page; the footer links every top-level page.

## Tools: the review loop

audit, screenshot, fix, redesign, audit.

```bash
python3 tools/brand/build_brand_book.py          # tokens; contrast gate
python3 tools/website/sync_chrome.py             # header, dock, footer, system.css + scale.css on every page
python3 tools/website/token_lint.py              # raw font sizes, radii, durations, hexes: ratchet
python3 tools/brand/brand_lint.py website        # off-brand colours: ratchet
python3 tools/seo/site_audit.py                  # SEO, links, sitemap
python3 tools/hygiene/run_all.py                 # padding, spacing, type, buttons, layout, loading (Playwright)
cd tests/website && node ui_audit.mjs && node ui_scale.mjs && node ui_type.mjs   # interaction, device scale, type
python3 tools/website/screens.py shoot OUT       # every page, phone/tablet/desktop; sheet OUT; compare BEFORE AFTER OUT
```

`screens.py` freezes motion so a shot is the page as it reads, writes per-viewport contact sheets, and ranks a before/after compare by how much changed. Set `SITE_DIR` to shoot or check another copy of the site (a snapshot from `git archive HEAD website`). Set `CHROME_PATH` to use the installed Chrome.
