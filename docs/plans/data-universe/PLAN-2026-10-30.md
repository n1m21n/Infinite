# Generate Samples, reopened: the work list (2026-10-30)

The close doc ([CLOSE-2026-10-30.md](CLOSE-2026-10-30.md)) closed the fix pass after the owner's 2/10 review. The project
itself (GOAL.md) is open. This is the list the owner signed off on 2026-10-30 (`docs/DECISIONS.md`), in working order.
Results still go to HANDOFF.md; bars are unchanged; a miss is recorded as a miss.

**Where we are going:** a generator that learns. Today only the role critic is a neural net (an MLP that judges takes);
the generator is style cards, hand rules and seeded draws from banks, and the note model is n-gram counts. Each model below
becomes neural only when it beats the simpler one on held-out data.

```
 measured data ──> learned models ──────────────> generator draws ──> takes the player keeps
 (renders, MIDI,   note: LSTM/transformer vs n-gram  (voices, notes,        │
  effects, DEAM)   sound: knob -> sound MLP          knobs, effects)        │
                   valence, critic (shipped)              ^                 │
                                                          └── local profile ◄┘ (per player, on the Mac)
```
