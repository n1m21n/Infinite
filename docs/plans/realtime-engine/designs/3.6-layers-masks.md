# 3.6 Material layers + masks (waiting for owner)

Full spec: REALISM.md R1. This page settles its open choice and the engine cost.

## Graph: chaining (decided)

```
 Material (rust) ──► layer ┐
 mask (image / Field / built-in) ──► layer mask ─┤
 Material (paint) ───────────────────────────────┴► Material (shoe) ──► Scene 3D
```

- Material gets two inputs: `layer` (a Material) and `layer mask`. A layered Material can itself be a layer, up to
  3 deep (R1's "two extra layers"); deeper chains show a node warning and drop the extra.
- No new node type. Built-in masks (cavity, edge, AO, world up, height, noise) are a `Mask` choice on the layer mask
  row when nothing is wired: one dropdown plus Level and Softness knobs.

## Engine

| Part | Choice |
|---|---|
| Record | MatRec grows 256 → 272 B (all 64 floats are used today): `layerNext`, `layerMask`, `maskLevel`, `maskSoft`. Layers are extra MatRec rows in the same buffer, linked by `layerNext` |
| Blend | inputs blended top-down by mask before one BSDF evaluation (R1); `Two lobes` mode on the top layer keeps both specular lobes (skin, wet) |
| Masks | cavity/edge per vertex from curvature on topology change (CPU, once), AO from the existing bake, world up and height per pixel/hit, noise via the 3.3 library |
| Paths | raster, live, settle read the same blended inputs (shared header) |
