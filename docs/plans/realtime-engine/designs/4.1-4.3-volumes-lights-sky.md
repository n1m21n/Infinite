# 4.1–4.3 Volumes, light shapes, sky (waiting for owner)

Specs: DESIGN G1, G8; REALISM R15. Each row below is one approval.

## 4.1 Volumes

```
 Volume [Output: Image | 3D]  ──► Scene 3D  (bounds + density + colour + anisotropy g)
```

| Path | Method (clean room: papers) |
|---|---|
| Settle | delta tracking (Woodcock), ratio-tracked shadow transmittance, NEE per scatter, Henyey–Greenstein phase |
| Live, raster | froxel grid ~160×90×64 at half res (Wronski 2014, Hillaire 2015), key light by RT shadow, others by shadow map, temporal reprojection; budget ≈ 2 ms on M2 |
| Density | homogeneous first (box or world fog), then the Volume node's own noise, then Field Pixel 3D grids |

New: the `3D` Output choice on Volume; a world fog row (Density, Colour, g) on Scene 3D's World. Cases
`vol_fog_sun`, `vol_smoke`, `vol_world_haze`; settle ≤ 0.05, live ≤ 0.15.

## 4.2 Light shapes, IES, linking

| Addition | Light node control | Engine |
|---|---|---|
| Disc / ellipse area | Shape: Rectangle / Disc | same sampling as the rectangle, disc mapping (Shirley–Chiu concentric) |
| Spread | knob 0–180° | cone limit on area emission |
| IES | file slot (`.ies`) | 1D/2D table per light, sampled by angle; parser written from the LM-63 public format |
| Light linking | per-light "Lights only" object list | Metal intersection masks in the TLAS; raster via a per-light instance mask |

One case each: `light_disc`, `light_spread`, `light_ies`, `light_link`.

## 4.3 Sky and atmosphere

World gains `Sky: Gradient | Physical`. Physical = Hillaire 2020 (transmittance + multiple-scattering LUTs) from
the sun direction already in the scene; sun colour follows elevation; aerial perspective shares 4.1's froxel grid.
Knobs: Turbidity (aerosol), Ozone, Altitude. Cases `sky_noon`, `sky_sunset` vs Cycles' multiple-scattering sky,
settle ≤ 0.05.

## Order once approved

4.3 sky (smallest, no new objects) → 4.2 disc + spread → 4.1 homogeneous settle → 4.1 live → IES → linking.
