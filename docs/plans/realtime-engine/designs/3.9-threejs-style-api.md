# 3.9 three.js-style API on Sketch 3D (waiting for owner)

Owner listed three.js beside Sketch, Field and GLSL as the script edge. Infinite has no three.js node; Sketch 3D
(JavaScript, quickjs) already builds geometry by rules. Proposal: no new engine, a familiar API layer.

| Part | Plan |
|---|---|
| Calls | `new Mesh(new BoxGeometry(w,h,d), new MeshStandardMaterial({color, roughness, metalness}))`, `scene.add`, `position/rotation/scale`, `InstancedMesh` |
| Maps to | Sketch 3D geometry out + Material params (Principled subset); instances → Instances path |
| Not included | three.js renderer, shaders, WebGL; the code is our own clean-room API with the same names (MIT three.js is not vendored) |
| Runs | per frame on CPU like Sketch 3D; shading stays on the GPU engine (raster, live, settle) |
| Why | agents and users already know these calls; pasted scene snippets become Infinite patches |
| Test | 3 snippets (box + sphere + plane, instanced grid, material sweep) vs the same scene built with nodes: identical render (T0) |

Order once approved: after Phase 3 Field material domain, since material params map onto it.
