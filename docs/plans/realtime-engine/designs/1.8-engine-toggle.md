# 1.8 Engine choice on Render 3D + Milestone 1 demo (waiting for owner)

## Today

| Where | What |
|---|---|
| Render 3D, 3D View Render tab | `Engine` combo: Raster, Path trace (GL tracer) |
| Hidden | `liveEngine` param + `INFINITE_LIVE_ENGINE=1..15` env (feature bits 1 GI, 2 shadows, 4 reflections, 8 settle) |

The Metal engine (live and settle) is only reachable by env today.

## Proposal

```
 Engine: [ Raster | Live | Path trace ]
                      │        └─ Metal settle when the engine is available, GL tracer otherwise
                      └─ Metal live (RT shadows, reflections, half-res GI); falls back to Raster
                         with the engine error on the node when Metal fails
```

| Choice | Draws with | Export | Platforms |
|---|---|---|---|
| Raster | GL forward + probe GI (today) | same | all |
| Live (new) | Metal live engine | live preview export (1.7) | macOS; Linux/Windows after 1.9, hidden until then |
| Path trace | Metal settle (GL tracer where Metal is absent) | settle, denoised (1.5) | all |

- One combo, three words, no sub-text (short UI text rule). The engine's feature bits stay internal.
- Old patches: `engine` 0/1 keep their meaning (Path trace stays index 1 in saved files; Live is stored as 2,
  shown in the middle).
- `INFINITE_LIVE_ENGINE` stays for the harness only.

## Demo patch (Milestone 1)

Boat on ocean (README "Boat-on-ocean scene"), Engine = Live, Audio Analyze bands 1–3 drive sun elevation, boat
emission and wave height through Smooth; 60 s at 1080p exported with the preview export. Posted to Discord as the
C9 check, then the go/no-go on R5–R7.

## Decisions taken (owner may overturn)

- Live goes in the existing combo, not a new toggle row.
- Path trace switches to Metal settle where available, only if the sweep shows settle at or below the GL tracer's
  FLIP on every case (to be measured before the switch; not yet compared case by case).
