## What's new in v0.4.25

### Features

- **CV Recorder** (Modulators): patch in any modulator, hit **Rec**, then hit it again to stop — the take loops back automatically. `speed` sets the playback rate (changes glide smoothly), `low`/`high` set the output range, and takes are timed in beats and saved with the patch.
- **Velocity to CV** (Modulators): turns note velocity into a 0..1 modulator, with an adjustable velocity range (`low`/`high`).
- **Note nodes no longer need Start Audio.** Random Note, the sequencers, Note to CV and Velocity to CV keep running and driving modulation with the audio engine off (synths still need it to make sound), and they no longer need an Audio Out in the patch.
- **Note to CV, Velocity to CV and CV Recorder look and edit like the other modulators**, with the yellow live graph and a parameter panel.

### Fixes

- Fixed **Predictive Modulator** bindings showing amber like a regular modulator; they now read green like the rest of the Prediction category (knob, cable, Modulation Matrix and preview).
- **Predictive LFO and Predictive Macro can only drive parameters** — cabling them into another node is refused everywhere, and the refused drop now says why.
- Modulator value meters use a fixed 0..1 axis, so a flat or slow signal no longer looks like it is jumping around.
