## What's new in v0.4.2

- Add a Prediction category that learns how you move: Predictive LFO, Predictive Modulator, Predictive Notes and Predictive Macro; Shift-grab takes a control back instantly
- Add per-clip modulation bypass on the timeline, and Make Unique for clips that share a source
- Modulation Matrix shows category dots and live sparklines
- Add CV Recorder and Velocity to CV (Modulators); note nodes no longer need Start Audio
- Analog synth gets a tuning header matching Oscillator and Wavetable, and a Comb filter type
- Better Random Note and Chorder algorithms; Chorder's rate uses the standard musical divisions
- Fix Transform and other geometry operators dropping point clouds and curves
- Fix timeline clip trim leaving the source offset out of sync, and clip inspector fields not typing in their own units
- Fix 3D text glyph holes self-intersecting and Spout receive showing black on GPUs without interop
- Fix MIDI CC from 14-bit controllers (e.g. Pioneer DDJ-FLX4) jumping erratically
- Fix double-click-to-type on sliders and knobs snapping to a rounded value or stealing keystrokes
- Fix Video In crashing on Windows at a fixed resolution, and a Linux build error that broke the AppImage
- Predictive Modulator bindings now read green; Predictive LFO and Macro can only drive parameters, and a refused cable says why
