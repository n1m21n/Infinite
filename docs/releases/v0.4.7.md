## What's new in v0.4.7

- Add NDI In and NDI Out (Utility) to send and receive video over the network; the NDI runtime is not bundled and the node says so when it is missing. NDI® is a registered trademark of Vizrt NDI AB.
- Add MIDI File (Synths): plays a `.mid` on the transport with transpose, loop, speed and a piano-roll preview
- Add MPE input to MIDI Notes, plus Note Pressure and Note Slide controllers; pitch bend and channel aftertouch are now MIDI-learnable
- Add Key-Snap (Effects): polyphonic scale snap with glide
- Add Spectrum Slide (Effects): a two-input spectral morph
- Add Shape Resonator (Synths): rings the vibration modes of a geometry input
- Drum Sequencer: 32 steps, a 141-groove library with A/B/C slots, per-lane accent pitch and a bundled kit (groove table from Ricardo Palmieri's fork, PR #24)
- Looper: the loop saves with the patch, REC snaps to the grid, and Undo steps back one layer at a time
- Group 3D carries more than four objects into Render 3D; Material gains a texture-alpha switch; Shape outputs straight alpha
- Output window has a transparent framebuffer, so node alpha shows with no checkerboard (#26)
- Add full keyboard-only navigation of the canvas and node parameters
- Add a Language setting (beta): English, Español, Deutsch, 中文, 日本語, Русский; node and parameter names stay in English
- Add an interface font choice (Inter or Atkinson Hyperlegible), 4.5:1 text contrast in every theme, and Cmd/Ctrl +/- interface scaling
- Dropdowns over 12 items get a search box, and node search treats hyphen and underscore as a space
- Fix File > New leaving the old sound playing, and a start-up race on the audio thread
- Fix plugin-node races and two stack-lifetime bugs in Molder and Audio Plugin
- Fix Windows timeline render (`.mov`, Desktop folder, non-ASCII paths) and Windows/Linux resource paths; the Windows package now ships `Resources/`
- Add `--frame --repeat N` for headless multi-pass renders; CI gains ASan/UBSan and clang-tidy jobs
