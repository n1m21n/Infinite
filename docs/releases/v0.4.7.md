## What's new in v0.4.7

### Headline: video over the network, and MIDI in and out

- **NDI In and NDI Out** (Utility): send any image to other apps on your network as an NDI source, or receive one as a texture. NDI In lists the sources it finds in a dropdown. The NDI runtime is not bundled: install it from ndi.video (Infinite shows a note on the node when it is missing). Bypassing NDI Out withdraws the source. NDI® is a registered trademark of Vizrt NDI AB.
- **MIDI File** (Synths): plays a `.mid` on the transport's beat timeline, with transpose, loop, velocity, a piano-roll preview and drop-to-spawn. It has its own playhead (position 0 to 1 starts playback) and a speed knob, or can follow the file's own tempo map. Format 0/1/2, SMPTE and RMID files load, unclosed notes end cleanly, and the drum channel is not transposed.
- **MPE input:** MIDI Notes gains an `mpe` switch. Per-note pitch bend comes from the member channels, with master bend on top, and new Note Pressure and Note Slide controllers expose the other two MPE dimensions.
- **Pitch bend and channel aftertouch** are bindable controls (MIDI learn) on macOS, Windows and Linux.

### New nodes and features

- **Key-Snap** (Effects): polyphonic scale snap. Notes in what you play are pulled to a scale and root (or the global key) with glide, using a peak-locked phase vocoder. Note lines show off-scale, in-scale and root in separate tints.
- **Spectrum Slide** (Effects): a two-input spectral morph. Peaks in one sound glide to peaks in the other instead of cross-fading.
- **Shape Resonator** (Synths): rings the vibration modes of a geometry input. It accepts surfaces, ring point clouds and curves, re-solves on a worker thread, and stays silent on input it cannot use.
- **Drum Sequencer:** 32 steps in two 16-step pages, a groove library (141 grooves) with a category/groove picker and A/B/C slots, per-lane accent pitch, lane role headers, and a bundled basic drum kit. Groove table and several of these features come from Ricardo Palmieri's fork (PR #24).
- **Looper:** the loop is saved with the patch, a REC pressed just after a grid line starts on that line, and Undo steps back one layer at a time.
- **Group 3D** carries more than four objects into Render 3D. **Material** gains a texture-alpha switch that feeds the sorted translucent pass.
- **Shape:** straight alpha output, and its edge keeps the shape's colour.
- **Audio Out:** a live option skips terminal delay compensation.
- **Output window:** transparent framebuffer, so node alpha passes through with no checkerboard when windowed (#26).
- **Art Gallery:** Sheep and Hydra.
- **Launcher card:** a small card with the Infinite mark plays in its own window at start, and the main window appears when it ends.

### Keyboard, accessibility and interface

- **Keyboard-only use:** Tab and the arrow keys walk nodes, Enter selects, F frames, Esc leaves. Tab then walks the active node's parameters, arrows change them, Shift+arrow selects a neighbour, Alt+arrows nudge selected nodes (one undo entry per burst), Cmd/Ctrl+U ungroups, and Tab reaches dropdowns and checkboxes. Popups and panels take ImGui navigation while they have focus.
- **Interface font choice** in Preferences: Inter or the bundled Atkinson Hyperlegible, applied live. Fonts now cover Latin Extended, Greek, Cyrillic and common punctuation.
- **Themes:** text and dim text reach 4.5:1 contrast on window and panel backgrounds.
- **Cmd/Ctrl +/-** scales the interface; help tooltips are opt-in.
- **Dropdowns** over 12 items get a search box (accent-insensitive).
- **Node search** treats hyphen and underscore as a space, so "key snap" finds Key-Snap.
- **Settings:** double-click any slider to type a value, and typed values clamp.
- **Pins and modulation dots** have a hit area of at least 20 points.
- Shortcuts window wraps long descriptions; hover-to-type sees a field on the frame it takes focus; double-clicks that land on a floating window no longer spawn the canvas node picker.

### Fixes

- **File > New** republishes the audio topology, so the old sound stops and retired nodes drain.
- **Audio start race:** the audio thread parks on an empty topology until the device opens.
- **Plugin node:** the plugin handle is held for the whole audio block, so destroy, re-prepare and MIDI cannot race it. Windows plugin editors save and restore the WGL context. The plugin browser keeps Remove on screen with long paths.
- **Molder and Audio Plugin:** two stack-lifetime bugs found by the sanitizer are fixed.
- **Windows timeline render:** `.mov` through the MPEG-4 muxer, the real Desktop folder, UTF-8 safe paths, and the output folder is created. A failed timeline render now says why.
- **Windows/Linux:** groove names are ASCII-folded for the UI font, and bundled resources resolve with UTF-8 paths. The Windows package ships `Resources/` next to `Infinite.exe`.
- **Help popup:** H closes it again.

### Under the hood

- **Quality gates:** an ASan+UBSan job and a clang-tidy baseline in CI; the audio parameter sweep now runs on multi-block windows with a spectral signature, and Drum Sequencer, PaulStretch, Molder, Audio File and the seeded Sampler, Granular, Slicer rigs are real checks (150 previously baselined parameters now pass).
- **Headless:** `--frame --repeat N` renders several passes in one process with a patch reload between them.
- **AppImage:** appimagetool is pinned to a versioned release.
- `main.cpp` is split into smaller files; behaviour is unchanged.
