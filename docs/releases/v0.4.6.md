## What's new in v0.4.6

- Add a headless engine: `--render` writes a movie, `--frame` writes stills, with status JSON and exit codes for scripts (Windows and Linux too; Linux needs `xvfb-run`)
- Add `--frames-dir`, `--node` and `--codec prores4444` (macOS) for frame sequences, tapping any node, and alpha movies
- Add `--audio-summary`, `--stems`, `--notes` and `--note-map` for measuring and driving a patch's audio
- Add `--contact-sheet`, `--explain`, `--describe` and a strict `--validate` to inspect a patch before rendering
- Add `--set <node>.<param>=<value>` for per-shot parameter overrides
- Running app: live reload when the patch file changes, live validator warnings on nodes, an RPC, and `infinite open <patch>` on Windows and Linux
- Add a patch-authoring skill and a Headless User Guide (PDF)
- Add Looper (Synths): record a self-ending take, then loop, dub and clear, with latency compensation
- Add MPC (Synths): a 16-pad sample player on notes 36 to 51 with One shot, Gate and Loop modes
- Add Sampler fade in/out, MIDI learn on any parameter (right-click), a Metronome click in the top bar, an audio round-trip latency readout, and Windows low-latency output
- Fit gains X/Y offset; video loop wrap works when the duration is unknown; Macro Trigger fires Looper buttons and MPC pads
- Fix interface scaling on high-DPI monitors (Windows and Linux); UI Scale no longer needs a restart
- Fix Render 3D translucency, Join colour handling, and several geometry nodes dropping curves or point size
- Fix the device mix counting a signal twice when it goes to both Audio Out and an Output
- Fix saving in the Linux AppImage (#25), the macOS recorder finishing late, and patch files with a BOM or Windows line endings
- Website v2, refreshed Node Reference Manual, and a Field Language "What's new since v1" addendum
