## v0.4.6 (2026-10-01)

## What's new in v0.4.6

### Headline: the headless engine

Infinite can now render without a window. Patches are plain `.inf` text files, and the same patch gives the same frames and samples every time.

- **Render from the command line:** `--render` writes a movie, `--frame` writes still frames, with a status JSON and exit codes for scripts. `--frames-dir` writes a numbered PNG sequence plus `frames.json`, `--node` taps any node's image, and `--render --node` encodes a tapped node to mp4/mov with no Output node.
- **Alpha movies:** `--codec prores4444` (macOS).
- **Audio:** `--audio-summary` measures a patch's sound, `--stems` writes one WAV per source, and `--notes` / `--note-map` inject film events as sample-accurate note-ons. `--render --start` moves the audio clock.
- **Look before you render:** `--contact-sheet`, `--explain` (graph, effective bypass, modulation lag, clips, geometry counts and bounding box, effective material), `--describe` (every node's pins, params and what its buttons do) and a strict `--validate` with coded errors and warnings.
- **Per-shot control:** `--set <node>.<param>=<value>` overrides a parameter after load.
- **Linux and Windows:** headless runs on both. On Windows a console shim makes exit codes and JSON reach cmd and PowerShell. Linux needs a virtual display (`xvfb-run`).
- **Driving a running app:** live patch reload when the open file changes, validator warnings shown live on nodes, and an RPC for batches, loading and validating patch text, rendering the current output, describing nodes and explaining the running graph.
- **Open in the running app:** `infinite open <patch>` reuses the running window on Windows and Linux.
- **A skill for it:** a generated patch-authoring skill and a headless user guide (PDF) are in the repo.

### New nodes and features

- **Looper** (Synths): record a take that ends on its own, then loop, dub and clear. Takes are shifted by your interface's measured latency.
- **MPC** (Synths): a 16-pad sample player with One shot, Gate and Loop modes, per-pad volume, pitch, pan, speed, fine tune and fades, and optional sync to a musical division. Notes 36 to 51 play the pads.
- **Sampler fade in / fade out.**
- **MIDI learn:** right-click any parameter to bind it to a MIDI control.
- **Macro Trigger** now fires Looper buttons and MPC pads on every trigger.
- **Audio round-trip latency readout**, plus Windows low-latency and exclusive output.
- **Fit** gains X/Y offset, so placing and fitting is one node per layer.
- **Video loop wrap** now works when the file's duration is unknown.
- **Metronome:** a Click toggle in the top bar. The click follows the transport (higher on the first beat of each bar) and goes to your speakers only, never into an Audio Out recording or an export.

### Fixes

- **Interface scaling on high-resolution monitors:** the whole interface (text, nodes, pins, minimap) now grows with the monitor's scale on Windows and Linux, and follows live when you move the window between monitors. The UI Scale slider scales the entire interface and no longer needs a restart. macOS is unchanged.
- **Render 3D:** translucent objects are drawn in a sorted pass.
- **Join** always preserves colour and no longer invents colour from instances.
- **Geometry:** Transform applies its matrix to a curve, Switcher 3D forwards clouds and curves, Distribute on Faces re-bakes when the inherited material changes, and Material, Null 3D, Mapping, Set Color, Geometry Op and Cloth forward point size.
- **Audio:** the device mix no longer counts a signal twice when it goes to both Audio Out and an Output.
- **Gestures and predictors** advance on offline video time.
- **Linux AppImage:** saving works (issue #25).
- **macOS recorder:** waits for the file to finish writing.
- **Patch reader:** ignores a byte-order mark and Windows line endings.

### Website and docs

- Website v2 in the launch-film language, lighter for slow networks.
- Node Reference Manual refreshed with the missing node types; the MPC card is new.
- Headless User Guide linked from the README and website.
- Field Language Manual gains a "What's new since v1" addendum: offset reads of pixel state, `.at()` neighbour reads, state tables, declared audio inputs and note history.


## v0.4.5 (2026-09-26)

## What's new in v0.4.5

- Add an Audio Meter node (Utility): stereo L/R bars on a shared -60 to +3 dBFS scale with RMS inside peak, a peak-hold line, and a per-channel max-peak readout that turns red at 0 dBFS. Audio passes through unchanged, so it can hang off any cable as a tap; click to clear holds and clip. Bars drop to zero within 100 ms of the audio stopping.
- Fix VST3 plugins with sidechain inputs or aux outputs (most compressors, Kontakt) rendering from their left channel only: every bus is now negotiated, main buses get stereo, and the note input bus is activated so strict plugins receive notes. macOS, Windows and Linux.
- Fix VST3 scanning silently dropping every plugin after a slow one: the scan timeout is now per plugin instead of one deadline for the whole batch, and a crash or hang is blamed on the plugin that caused it rather than the next one in the list. macOS, Windows and Linux.
- Fix Shift-drag gesture loops stepping only every 30 frames when their node is off screen (including renders and recordings taken while zoomed in), and freezing on a node with its eye closed. Performance-panel writes to off-screen or collapsed extra targets are no longer lost.
- Fix the Windows build failing to link (DXGI), which could leave a release without Windows binaries.


## v0.4.4 (2026-09-25)

## What's new in v0.4.4

### Features

- **Predictive Quantize** (Prediction): a groove quantizer, not a grid one. Wire notes in and it learns the spacing between your onsets while correcting them in the same pass. There is no Learn button: it keeps adapting as you play, and the profile is shared by every instance in every patch. Chords stay together instead of arpeggiating apart.
- **Predictive Velocity** (Prediction): a learned dynamics curve. It listens to the velocities you play and remaps incoming notes onto your own loud/soft shape, always on and shared like Predictive Quantize. `mix` 0 leaves notes untouched.
- **Predictive Rhythm** (Prediction): press Learn like Predictive Notes, but pitch is learned as an interval from a `root` note, so it plays back a repeating pattern anchored on one note. Root auto-detects after Learn; changing it transposes the pattern live without relearning.
- **Predictive Coloring** (Prediction): learns what graded footage looks like to you and grades incoming frames toward it. Press Learn on already-graded footage, or leave `self normalize` on to auto-level without a profile. `wander` lets the grade drift gently among looks it has actually seen.
- Predictive Quantize, Velocity and Rhythm show a **confidence badge**, and their status line reports dropped captures instead of losing them silently.
- Predictive Notes and Rhythm build a cross-session "house style" that blends into what each instance learns. Duplicating or copy-pasting a Learn-based Predictive node now starts the copy fresh instead of cloning its trained model.
- **Drift (Predictive LFO)** gains `depth` (pulls a learned range that sits too high back toward centre) and exposes `smoothing` again.
- Moves / Predictive Macro keep their learned movement history across restarts instead of re-learning for about a minute each launch.
- Dropping an audio file on empty canvas now asks which node to load it into (Sampler, Audio File, Drum Sequencer, PaulStretch, Granular, Grain Molder, Molder) instead of always spawning one.
- Right-click a modulated knob → **View in Modulation Matrix** opens the panel and flashes that binding's row.
- The audio xrun indicator now counts real dropouts: late audio blocks plus the ones the device reports. Its tooltip shows the two separately.

### Performance

- **Projectors hold a steady 60 fps during a live set.** They now pace to their own display's refresh even when the canvas window is covered. In our live-performance benchmark, missed frames went from 12% to 0% and the worst frame interval from 50 ms to 17.6 ms.
- **The canvas is locked to 60 fps while panning big patches.** Off-screen nodes skip drawing their body, and Noise/Shape (and the filter chains after them) no longer re-render every frame when nothing changed. On 300-400 node patches, frame time dropped by 79-89%.
- **Lower audio CPU on heavy patches.** Reverb is faster (SIMD, cached coefficients, a cheaper LFO bank), and on a 24-voice patch the worst-case audio load fell from about 53-61% to 40-45%. The UI on that patch went from about 13 fps to 60 fps.
- **Video playback (macOS):** each clip decodes on its own thread, only new frames are uploaded, and there is no per-frame copy. Four 4K clips now play in real time with no dropped frames.
- Gaussian Blur, Box Blur, Bloom and Diffuse Glow run as two passes (about 4x less GPU time on heavy chains). Time-driven filters cache while the transport is stopped.
- Two-pass filters share one scratch buffer, cutting GPU render-target memory by about 27% on heavy compositing patches.
- The Ocean node is about 6x cheaper per frame. Audio Filter's response curve is computed directly instead of simulated, so modulated filters no longer stall the canvas.

### Fixes

- Fixed stuck notes and skipped note events when rewiring note cables while audio is playing.
- Fixed a crash in the Drum Sequencer when swapping a lane's sample while voices were still sounding.
- MIDI bindings (performance matrix, MIDI CC, MIDI Trigger) now survive a relaunch on macOS instead of being orphaned.
- If the saved audio output device is gone, Infinite now falls back to the default device instead of starting silent.
- Modulation no longer creates undo entries or marks the patch dirty. A modulated dropdown or toggle used to flood the undo history, and one dropdown pick counted as two undo steps.
- Fixed a thin vertical seam in the HDRI background.
- Exported movies get exact frames from video clips. Export A/V sync measures 0 dropped frames and sub-millisecond drift.
- Camera input reuses its texture instead of reallocating it every frame.
- Windows: Syphon/Spout Out no longer claims a receiver is connected when it can't tell. The node now says "Clients: not reported".
- Linux: video clips no longer re-copy and re-upload a frame that hasn't changed.
- Removed the quantise option from Note Capturer.

## v0.4.25 (2026-09-20)

## What's new in v0.4.25

### Features

- **CV Recorder** (Modulators): patch in any modulator, hit **Rec**, then hit it again to stop — the take loops back automatically. `speed` sets the playback rate (changes glide smoothly), `low`/`high` set the output range, and takes are timed in beats and saved with the patch.

### Linux

**Infinite ships on Linux for the first time**, as a single downloadable file (`Infinite-x86_64.AppImage`) — no installer, no extra packages to install first.

It's been tested on Ubuntu 22.04, Ubuntu 24.04, Debian 12, Fedora, and Arch Linux, covering plugin hosting (VST3, with plugin windows), audio and MIDI, video and camera, and background removal.

**Please note:** this is an early-access build. It's been thoroughly tested in automated environments, but hasn't yet been through a round of real-world use on real hardware — different GPUs, audio interfaces, MIDI controllers, and desktop setups. A native Wayland desktop session hasn't been verified yet either (X11 is). If you run into issues, please report them on [GitHub issue #14](https://github.com/n1m21n/Infinite/issues/14) — that feedback is exactly what this release needs.

## v0.1 (2026-08-16)

## Infinite v0.1 — Realtime Modular Visual & Audio Synthesizer

A realtime modular node-based environment for visual synthesis, 3D geometry generation, and audio sound design, connecting sound and visuals over a unified signal graph.

- 80+ real-time 2D/3D shader and generation nodes, including reaction-diffusion and feedback loops
- Parametric 3D geometry — procedural meshes, point clouds, particle systems, PBR lighting, custom camera rigs
- Audio-reactive vertex displacement, wave terrain generators, and image-to-point transforms
- Multi-paradigm synthesis — wavetable, physical modeling, granular, drum sequencers, PaulStretch time-stretching
- 15+ built-in DSP effects — Reverb, Chorus, Phaser, Delay, Dynamics, Distortion, Parametric EQ
- Native AU and VST3 plugin hosting
- Full MIDI I/O, hardware clock sync, and parameter mapping
- Route any audio signal, envelope, LFO, or curve to modulate visuals, or drive audio from 3D positions and image luminance
- High-performance node canvas with live cable signals, color coding, and draggable sub-patching

macOS 11.0 Big Sur or later (Apple Silicon & Intel). First launch: right-click `Infinite.app` → Open → Open.
