## v0.4.5 (2026-09-26)

## What's new in v0.4.5

- Add an Audio Meter node (Utility): stereo L/R bars on a shared -60 to +3 dBFS scale with RMS inside peak, a peak-hold line, and a per-channel max-peak readout that turns red at 0 dBFS. Audio passes through unchanged, so it can hang off any cable as a tap; click to clear holds and clip. Bars drop to zero within 100 ms of the audio stopping.
- Fix VST3 plugins with sidechain inputs or aux outputs (most compressors, Kontakt) rendering from their left channel only: every bus is now negotiated, main buses get stereo, and the note input bus is activated so strict plugins receive notes. macOS, Windows and Linux.
- Fix VST3 scanning silently dropping every plugin after a slow one: the scan timeout is now per plugin instead of one deadline for the whole batch, and a crash or hang is blamed on the plugin that caused it rather than the next one in the list. macOS, Windows and Linux.
- Fix Shift-drag gesture loops stepping only every 30 frames when their node is off screen (including renders and recordings taken while zoomed in), and freezing on a node with its eye closed. Performance-panel writes to off-screen or collapsed extra targets are no longer lost.
- Fix the Windows build failing to link (DXGI), which could leave a release without Windows binaries.

## v0.4.25 (2026-09-20)

## What's new in v0.4.25

### Features

- **CV Recorder** (Modulators): patch in any modulator, hit **Rec**, then hit it again to stop — the take loops back automatically. `speed` sets the playback rate (changes glide smoothly), `low`/`high` set the output range, and takes are timed in beats and saved with the patch.
- **Velocity to CV** (Modulators): turns note velocity into a 0..1 modulator, with an adjustable velocity range (`low`/`high`).
- **Note nodes no longer need Start Audio.** Random Note, the sequencers, Note to CV and Velocity to CV keep running and driving modulation with the audio engine off (synths still need it to make sound), and they no longer need an Audio Out in the patch.
- **Note to CV, Velocity to CV and CV Recorder look and edit like the other modulators**, with the yellow live graph and a parameter panel.

### Fixes

- Fixed **Predictive Modulator** bindings showing amber like a regular modulator; they now read green like the rest of the Prediction category (knob, cable, Modulation Matrix and preview).
- **Predictive LFO and Predictive Macro can only drive parameters** — cabling them into another node is refused everywhere, and the refused drop now says why.
- Modulator value meters use a fixed 0..1 axis, so a flat or slow signal no longer looks like it is jumping around.

### Linux

**Infinite ships on Linux for the first time**, as a single downloadable file (`Infinite-x86_64.AppImage`) — no installer, no extra packages to install first.

It's been tested on Ubuntu 22.04, Ubuntu 24.04, Debian 12, Fedora, and Arch Linux, covering plugin hosting (VST3, with plugin windows), audio and MIDI, video and camera, and background removal.

**Please note:** this is an early-access build. It's been thoroughly tested in automated environments, but hasn't yet been through a round of real-world use on real hardware — different GPUs, audio interfaces, MIDI controllers, and desktop setups. A native Wayland desktop session hasn't been verified yet either (X11 is). If you run into issues, please report them on [GitHub issue #14](https://github.com/n1m21n/Infinite/issues/14) — that feedback is exactly what this release needs.

## v0.2.4 (2026-08-29)

## What's new in v0.2.4

- Add the Performance Matrix (Shift+P): a dockable grid of controls you build from your own patch, so you can play a piece without touching the canvas — bind any parameter to a control, arrange it in Edit mode, then switch to Perform
- Performance Matrix ships ten control types: knob, vertical fader, horizontal slider, toggle, XY pad, momentary trigger, digital number box, radio selector, bipolar pan knob, and step gate ribbon
- One Performance Matrix control can drive several parameters at once, and an XY pad drives an independent set on each axis; right-click any parameter on a node to send it straight to the matrix
- Performance Matrix supports multiple pages (rename, duplicate, reorder), per-control colour tints and custom labels, select/copy/paste, and docking bottom, right, left or top — the whole surface saves and loads with the patch
- Add nine Macro nodes — Knob, Slider, Bipolar Knob, XY, Toggle, Trigger, NumBox, Radio Selector, Step Gate — in a new Macros category, so the same controls can live on the canvas as modulation sources
- Add Grain Molder, a sampler that slices audio into grains and rearranges them along a continuous blend between their original order and their level, brightness, or a random ranking
- Add three audio effects: Resonator Bank, Cycle Shaper, and Spec Blur
- Add cable visibility toggles — hide image and geometry, audio and note, or modulation cables independently, or all at once — so a patch stays readable while you perform
- Extend node bypass to audio, note, and 3D geometry nodes, add Bypass selection for bypassing several nodes at once, and fix 3D geometry sources ignoring bypass
- Add Shift+V to toggle the viewport panel
- Raise video export quality substantially on both platforms; the previous bitrate visibly mushed pixel art, flat colour fields, and fine generative detail
- Fix the app freezing at 100% CPU on any patch containing a Wavetable node — its two engines shared one internal control slot, which also meant modulating one engine's table, octave, semitone, filter, or warp silently drove the other's
- Fix closing a projector window corrupting other nodes' previews on the canvas
- Fix Performance Matrix page names containing spaces being split apart when a patch is reloaded
- Fix a repeated warning from 3D point cloud rendering flooding the log
- Windows: fix exported video coming out vertically mirrored
- Windows: fix projector and output windows rendering as a blank dark rectangle
- Windows: fix a fullscreen projector overhanging the bottom-right of the display
- Windows: fix point cloud sprites drawing far larger than intended, which could hard-reset the graphics driver on dense scenes
- Windows: add audio support for devices that negotiate a PCM rather than float mix format
- Windows: fix a use-after-free on the audio thread when the input device changes while an Audio In node is live, and a handle leak on every capture restart
- Windows: write a crash report and a rolling log to the app support folder when the app dies
- Windows: disable the sample rate and buffer size settings, which shared-mode audio has never been able to apply, with a tooltip pointing at Sound settings
- Update the website with a tutorial video, a decluttered navigation bar, and new typography

## v0.1 (2026-08-16)

## Infinite v0.1 — Realtime Modular Visual & Audio Synthesizer

A realtime modular node-based environment for visual synthesis, 3D geometry generation, and audio sound design, connecting sound and visuals over a unified signal graph.

- 80+ real-time 2D/3D shader and generation nodes, including reaction-diffusion and feedback loops
- Parametric 3D geometry — procedural meshes, point clouds, particle systems, PBR lighting, custom camera rigs
- Audio-reactive vertex displacement, wave terrain generators, and image-to-point transforms
- Multi-paradigm synthesis — wavetable, physical modeling, granular, drum sequencers, PaulStretch time-stretching
- 15+ built-in DSP effects — Reverb, Chorus, Phaser, Delay, Dynamics, Distortion, Parametric EQ
- Native AU and VST3 plugin hosting
- Full MIDI I/O, hardware clock sync, and parameter mapping
- Route any audio signal, envelope, LFO, or curve to modulate visuals, or drive audio from 3D positions and image luminance
- High-performance node canvas with live cable signals, color coding, and draggable sub-patching

macOS 11.0 Big Sur or later (Apple Silicon & Intel). First launch: right-click `Infinite.app` → Open → Open.
