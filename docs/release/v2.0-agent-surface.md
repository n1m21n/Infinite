# v2.0 agent surface: coverage and gaps

Lane: `release/2.0-agents-mcp`. Scope: the MCP server, the npm library, the `infinite` command, the headless guide,
the in-app agent finder and Field Guide cards, and the skill generators. No app build was run; no version numbers
were changed.

Audit tool: `tools/agent-surface/check_surface.py` (`verbs`, `mcp`, `nodes`; exit 0 pass, 1 gap, 2 usage).

Notes on the numbers:

- The built app at `/Users/namansoni/Infinite/infinte-base/build` is 475 commits behind this branch (its source is an
  ancestor of HEAD). It reports 352 node types and an older help text, so its `--cli nodes` list is not used for
  coverage. Its `find-eval` numbers are the only finder numbers available, and they describe the old finder.
- The Field Guide card match is by normalised name. A card that covers several types under one name (for example
  "Twirl, Pinch/Punch & Ripple") counts only for the name it carries, so the 81% is a floor.

## What changed

- `tools/manual/cards_everyday.py` (new): 45 Field Guide cards for everyday names that had none (Chorus, Crop,
  Posterize, Piano, Dynamics, Limiter, Lookup, Circle, ...). Text comes from each node's in-app help text. Merged into
  chapters 27 and 28 by `cards_v06.py`. `src/core/AgentDocs.h` regenerated with `tools/gen-agent-docs.py`; `--check` exits 0.
- `tools/agent-surface/check_surface.py` (new): the audit above.
- `tools/npm/infinite-engine`: README table lists all 12 tools; `init` output and the handshake test name say twelve.
- `docs/headless/GUIDE.md` and the `infinite` help text (`src/core/InfiniteCli.cpp`): `version`, and the `settings`,
  `show` and `view` subcommands. Help text only.
- `src/core/chat/NodeFinder.cpp`: bridges for `thicker`, `trim`, `colours`/`colors`, `wobbly`, `soften`; `distort` also
  reaches `drive` and `saturator`. `tests/chat/find_plain.tsv` holds the 32 plain asks.

## Gaps remaining

Nodes with no Field Guide card (69). Mostly shader nodes and a few primitives:
3D View, Array, Arrow, Cloth, Cube, Delete Selected, Difference, Extrude Selected, Feedback, Feedback 3D, Field Graph,
Field Modulator, Fur, Generate Samples, Geometry, Helix, Icosphere, Inset, Intersect, Line, Moves, Ocean, Piano Roll,
Plane, Point Trails, Ring, Scene 2D, Select, Shade (Brick, Bump, Checker, Combine, Coord, Curves, Fresnel, Geometry,
Gradient, Image, Layer Weight, Map Range, Mapping, Math, Mix, Noise, Normal Map, Ramp, Separate, Vector Math, Voronoi),
Shadertoy, Spectral Field, Sphere, Sweep, Torus, Torus Knot, Trails, Transform, Transform Selected, VMPC, Wavetable,
and the lower-case 2D names transform, gaussianblur, boxblur, diffuseglow, bloom, twirl, pinchpunch, ripple, liquify
(these are covered by combined cards such as "Gaussian / Box Blur" and "Bloom & Diffuse Glow", so they are a
naming gap rather than a missing description).

Finder misses on `find_nodes.tsv` (57 of 312, stale binary): mostly mesh and point-cloud asks (merge two meshes,
make every face a triangle, show only the edges), note-routing asks (send low notes one way and high notes another),
and some picture asks (cut off the edges of the frame, water drop waves across the picture).

Other inconsistencies found and not changed:

- `README.md` at the repo root and `website/` were out of scope and not touched. The npm README's last paragraph
  still says the `tools/mcp` server has twelve tools; `tools/mcp/README.md` says eleven, in a plugin repository that
  is not in this tree. One of the two should be updated before release.
- `docs/headless/Infinite_Headless_User_Guide.pdf` is built from GUIDE.md and is now stale.
- `tools/catalog` is the samples and library catalogue, not a node vocabulary; it was not used for node discovery.
  The node vocabulary is `scripts/node_vocab.py` plus `NodeFinder.cpp`.
