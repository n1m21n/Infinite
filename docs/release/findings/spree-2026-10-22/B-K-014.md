## Repro

1. Write a patch with a Render 3D node whose params hold `i samples 2147483647` (or 100000).
2. Run `Infinite --frame patch.inf 0.5 out.png` under the sanitizer build.

## Expected

The body reads the same antialias level the renderer uses (Render3DNode::Cook clamps the index to 0..3).

## Actual

UBSan at GeometryParams.cpp:1882: `shift exponent 2147483647 is too large for 32-bit type 'int'`. The body computed `1 << samples` from the raw int. In practice the wanted-AA readout shows garbage; there is no memory access.

## Fix note

The body clamps the index with the same table bounds as the renderer (`Render3DNode::SampleNames()`) before shifting. Release build: both fuzz cases render, rc 0. UBSan re-check is pending until the ASan build is free.
