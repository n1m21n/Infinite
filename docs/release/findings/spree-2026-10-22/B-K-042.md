## Repro

A Text 3D node with `s text` of N "A" characters and a Render 3D, `Infinite --frame`. Before the fix: N=1000 0.7 s, 5000 1.2 s, 20000 9.5 s, 50000 56 s. Finite work, so not a hang, but the UI stops for the whole cook.

## Fix

Text past 2000 characters builds no mesh and the node status says "text too long (max 2000 characters)". Ordinary text is a few words.
