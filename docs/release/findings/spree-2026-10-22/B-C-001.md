## Repro

1. Write a patch with `f size nan` (Reverb) or `f timeMs nan` (Delay, sync 0) or out-of-range values like `f feedback 1e6`.
2. Load or `--audio-summary` it; or send `/infinite/node/<i>/<key> nan` over OSC (ArgToParamText prints %.9g -> "nan").
3. Frequency: always reaches the node (Patch.cpp:175 `(float)atof(...)` with no isfinite / range clamp).

## Expected

Non-finite and out-of-range floats are rejected or clamped to the param's [min,max] on load and on OSC set.

## Actual

Runtime, 2026-10-22, `--audio-summary --duration 4` on Random Note -> Wavetable -> fx -> Audio Out:

| patch | sample peak | note |
|---|---|---|
| base (Reverb, defaults) | 0.382 | |
| Reverb `size nan` | 0.439 | finite, sounds |
| Reverb `predelay inf` / `-1e6` | 0.365 | clamped, fine |
| Reverb `decay 1e9` | 0.664 | finite, louder |
| Delay `sync 0`, `timeMs nan` | **0 (W_SILENT)** | **whole master silent, dry included** |
| Delay `feedback 1e6` | 0.764 | finite (feedback clamped downstream) |
| Delay `timeMs 1e12` | 0.342 | clamped, fine |

Mechanism: `std::clamp(NaN, lo, hi)` returns NaN (DelayKernel.cpp:92, DelayKernel.h:79), then `(int)d` on NaN is UB (arm64 gives 0, x86-64 gives INT_MIN) and `frac` is NaN, so every Read() is NaN; the line feeds back, so it stays poisoned.

## Blast radius

1. Owner: no single node. Delay (src/audio/dsp/DelayKernel.cpp:92, DelayKernel.h:79) is where it shows; the fault is at the param entry points.
2. Logic: missing input validation (not algorithmic, not cache). `std::clamp(NaN, lo, hi)` returns NaN; `(int)NaN` is UB.
3. Entry points that write a float param: Patch::Reader::Float (Patch.cpp:171; reached by patch load, paste NodeClipboard.cpp, OscApi.cpp:200, Rpc.cpp, PatchLoad.cpp), Expression::Evaluate (CookFrame.cpp:570, ExprGlobals.cpp:72, AnalyzeNodes.cpp:181), typed values (ModWidgets.cpp:272,1408, ModMatrixPanel.cpp:68), perf pad values (Patch.cpp:893-900).
4. Degrades: everything downstream of the poisoned node on the audio graph (NaN mixes into Audio Out, the master reads silent).
5. Pattern: 31 `std::clamp(SmoothedValue...)` / `(int)` casts across 22 dsp files share the NaN pass-through. Guarding the entry points covers all of them; only DelayLine::Read gets a kernel-side backstop (the one with feedback that never recovers).
6. Platforms: `(int)NaN` is 0 on arm64 and INT_MIN on x86-64, so the read index differs per OS; the silence happens on all.
7. Loophole check: a rejected value keeps the old one (same as a missing key), so old patches load unchanged; inf typed into a knob already clamped to max before and still does. Settings-file floats (PatchIO.cpp:321-465) are the user's own prefs, left out of scope.
8. Since: Reader::Float has used atof since 23295356 (2026-08-10); the expression path since param expressions landed. Bad state: NaN lives in the Delay line and its smoother until the node is deleted or the patch reloaded.
9. Harness: no test fed a non-finite value through a param entry point; AUDIOPARAMSWEEPTEST only sweeps in-range values.

## Notes

User-reachable without a hand-edited file: a param expression whose result is non-finite. FieldVM rejects `/0` and `%0` but OpPow (FieldVM.cpp:360) does not, so `=pow(-1,0.5)` gives NaN and `=pow(0,-1)` gives inf; Expression::Evaluate (Expression.cpp:45) returns it as success and CookFrame.cpp:584-594 maps it through std::clamp, which keeps NaN. Same via OSC `/infinite/node/<i>/timeMs nan`.

Fix shape: one isfinite guard at the param-write chokepoints (Patch::Reader::Float, Expression::Evaluate result, OSC ArgToParamText) plus clamp-to-[min,max]; and NaN-proof DelayLine::Read (`if (!(d >= 1.0f)) d = 1.0f`). Check other kernels that do `(int)` on a smoothed param the same way.
