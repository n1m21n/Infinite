## Repro

`float-Sampler-1e9.inf` / `float-Bouncing_Balls-1e9.inf` from `param_fuzz.py BIN OUT --kind float --values 1e9`.

## What happened

- Sampler: start 1e9 made `ReadSample` cast frame ~1.44e14 to int (SamplerNode.cpp:530). B-K-036 clamped pitch, speed and volume but not start, end or position.
- Bouncing Balls: the sim clamps ballSize to 0.01..0.3, but the body drew the raw value, so ImGui's circle segment count overflowed int (imgui_draw.cpp:658).

## Fix

Both nodes clamp in VisitParams, and `ReadSample` returns 0 for positions outside the buffer before it casts. clamp_check: 872 patches, 0 values changed.
