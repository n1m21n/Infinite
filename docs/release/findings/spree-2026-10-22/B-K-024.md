## Repro

Make a 32-bit float WAV that has a few NaN or inf samples, for example from a buggy export or a damaged file. Load it into Sampler or Granular with looping on, and play notes. Render with `--audio-summary`.

## Expected

The bad samples play as silence, or the file is refused.

## Actual

`non_finite_frames` counts the whole render. Each loop pass replays the NaN. Before B-K-023 it also poisoned every effect after the player for good. It reaches the master meters, and any recording or bounce of the master is NaN there.

## Fix note

Both `DecodeAudioFileToBuffer` implementations (AVFoundation on macOS, dr_libs on Windows and Linux) now end with `Platform::ZeroNonFiniteSamples`. So every caller gets clean data: Audio File, Sampler, Granular, Molder, Slicer, PaulStretch, Looper reloads, arrangement import and library preview. The cost is one pass over the samples at load, off the audio thread.

`INFINITE_DECODE_KEEP_NONFINITE=1` turns the zeroing off. Only the signal fuzzer sets it, because its Audio File stimulus has to play NaN on purpose.
