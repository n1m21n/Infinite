## Repro

1. A .gltf with one 3-vertex mesh, no normals, and an index accessor holding 0, 1, 60000. Or the same mesh with the index accessor's byteOffset set to 100000.
2. Drop it on the canvas, which calls GltfImport::DecodeCached.

## Expected

The file is refused as damaged.

## Actual

DecodeCached (GltfImport.cpp:213-307) parses and loads buffers but never calls cgltf_validate, and cgltf's accessor reads assume a validated file. The index of 60000 crashes in GenerateNormals (:184), which accumulates normals through `vertices[indices[i]]`, a write path (ASan BUS). The out-of-view byteOffset gives an ASan heap-buffer-overflow READ in cgltf_accessor_read_index (:307).

## Fix note
Verified 2026-10-22: DecodeCached now refuses a file that fails cgltf_validate, which checks accessor and buffer-view extents and the index bound. In the harness both crafted files are refused, a well-formed 3-vertex file loads, and all 14 .glb files in the repo (brand art, website, blender-bridge) still load. GLTFDROPTEST needs fixture paths passed in by hand and was not run.
