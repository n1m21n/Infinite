## Repro

1. Add a Field Element node (nothing wired into its input) and modulate "generate count" with an LFO, over any range.
2. Press Apply in the field editor, or rename the param that holds id 1 (on the default preset, `amp`) and Apply.

## Expected

The node's own controls keep their modulation as it was. A modulated field param that is deleted or renamed loses its binding, and the notice names that param.

## Actual

- **Range clamp:** every Apply clamps "generate count"'s modulation range to the field param's range. In the test it went from [10, 5000] to [1, 1], so the LFO no longer moves the control.
- **Rename:** renaming the id-1 param unbinds "generate count"'s LFO, and the notice reports the unmodulated param as dropped.
- **Stale binding:** a modulated field param that is deleted or renamed keeps its binding on pin 50+id.
- **Other nodes:** every Field node type and Sketch / Sketch 3D go through the same Reconcile. On each of them, field param id N lines up with the node's own control N.

## Fix note

Reconcile now uses `kDeclaredParamIndexBase + id`; the constant moved to ParamTable.h and AppShared's kFieldDeclaredParamBase now refers to it. The param self-test used to bind at the raw id, which matched the bug and not the UI. It now binds where DrawFieldParamSliders does, and the new section 4b covers the node's own control.
