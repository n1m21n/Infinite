## Repro

1. Copy assets/templates/notes.inf and add `transport 1e30 4 4 0 0`.
2. `Infinite --audio-summary that.inf out.json --duration 4` on the UBSan build.

## Expected

Tempo held to the app's own range (headless `--bpm` enforces 1..999; the stage tempo field 20..300).

## Actual

UBSan: `NoteNodes.cpp:177: 7.11111e+26 is outside the range of representable values of type 'long long'` in StepClock::Ticks on the audio thread. Transport::SetTempo (Transport.cpp:193) only floors at 1 and lets NaN through; PatchLoad.cpp:335 and ShowSet.cpp:223 pass file values straight in. The release build plays a fast drone (same as 999), no crash, and saves the value back unchanged.

## Fix note
Verified 2026-10-22 on an ASan+UBSan build: `--audio-summary` of the `transport 1e30` patch, and of the same patch with `transport nan`, gives 0 runtime errors and normal audio. Before the fix, 1e30 hit the float to int64 overflow at NoteNodes.cpp:177. A NaN tempo was also applied unchecked before; SetTempo now ignores non-finite input.
