## Repro

Patch: an Audio File node plays a file that starts with 0.25 s of NaN (or ±inf) followed by a clean sine. The file feeds an EQ (or Audio Filter, Chorus, Convolution Reverb, Delay, Drive, Flanger, Formant Filter, Frequency Shifter, Phaser, Reverb, Resonator Bank, Saturator, Shape Resonator, Spec Blur, Spectrum Slide or Wavetable Shaper), and that effect feeds the speaker. Render 3 s with `--audio-summary`.

In practice the NaN can come from a VST, a damaged float WAV, or an upstream node that divides by zero for one block (B-C-001 and the ShapeToParam finding are known sources).

## Expected

NaN while the bad input plays, then the effect processes the clean sine again.

## Actual

`non_finite_frames` covers the whole render after the burst. The filter state, delay line, reverb tail or oversampler stored the NaN, and every later block reads it back. The chain stays silent, or NaN after a master stage, until the patch is reloaded. The Mixer doesn't keep state, so it recovers by itself.

## Fix note

AudioEffectNode checks the kernel's wet block, and its own aligned dry block when it has one, after the kernel runs. If either contains a non-finite sample, it calls the kernel's `Reset()`, zeroes that wet block, and lets the raw input through as dry. Every kernel's `Reset()` only zero-fills, which was checked across all 87 bodies, so this is safe on the audio thread. The check is one `isfinite` pass per block.

The first version checked before `ProcessDry`. Drive's dry oversampler then took in the NaN after the reset and stayed stuck. The final version checks after both.
