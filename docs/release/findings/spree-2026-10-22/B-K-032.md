## Repro

Load a patch with a Gain node set to `f gainDb 1e9`, with nothing patched in. Or load a Velocity Curve with `f curve -1`.

## Expected

The gain is held to -60..12 dB and the curve to 0.25..4, as the knobs do.

## Actual

`DbToLinear(1e9)` is `powf(10, 5e7)`, which is inf. Silence times inf is NaN, so Gain outputs NaN. A live input gives ±inf. Mixer (`gain0..11`) and Audio In behave the same. Nothing clamps `gainDb` on the audio side, and the -60..12 dB knob binds only the UI. Velocity Curve does `pow(v, curve)`: with a curve of -1, velocities go above 1, and a velocity-0 note-on becomes inf.

B-K-026 drops 1e30 at load. 1e9 still passes, and so does any value from about 770 dB up.

## Fix note

Each node's `VisitParams` clamps the param to the knob's range, which is also the route for OSC, RPC, clipboard and presets:
- Gain, Mixer and Audio In `gainDb`: -60..12 dB. This matches the existing lane and clip gain clamps in Patch.cpp.
- Mixer `pan`: -1..1.
- Velocity Curve `curve`: 0.25..4.

No preset or test sets these outside their range.
