## Repro

Load a patch with a dither node set to `f uMode 1e9` (or set it by OSC or RPC) and render a frame:

```
Infinite --frame float-dither-1e9.inf 0.5 out.png --lenient --timeout 60
```

## Expected

The mode is held to 0..3, the range of its dropdown.

## Actual

The process exits 134 (abort) with no sanitizer report. Metal logs "Caused GPU Hang Error (kIOGPUCommandBufferCallbackErrorHang)", then "Ignored (for causing prior/excessive GPU errors)". The dither shader runs `bayer(p, uMode + 1)`, a loop of `uMode + 1` iterations per pixel. `FilterNode::BindUniforms` uploads `(int)1e9` (FilterNode.cpp:246), so every pixel loops a billion times and the GPU watchdog kills the command buffer. In the app, that means the display stalls and then the app crashes.

Same root as B-K-031: `Patch::LoadParams` → `FilterNode::VisitParams` stores any finite float with no range check. B-K-026 stops only |v| ≥ 2^31. The path is open for every `FilterDef`: file load, OSC, RPC, clipboard and presets.

## Fix note

`FilterNode::VisitParams` holds every non-colour param to its def's `minVal..maxVal`. Enums carry `0..options-1` (FilterDefs.cpp `E()`). Colours are left alone because they have no range.

Blast-radius checks before the fix:
- **Saved patches:** `tools/bughunt/clamp_check.py` with the 168 ranged filter params found 0 of 855 tracked patches with a value outside them.
- **Other writers:** only the startup demo calls `SetParamValue`, and with in-range values (Startup.cpp:3081). Knobs are drawn from the def.
- **No GL in the load path:** a FilterNode builds and destroys without a context (DestroyFbo skips zero ids), so the test runs in the headless DSPTEST.

## Lesson

A shader loop bounded by a uniform is a GPU hang waiting for one large value. The CPU-side clamp covers filters. Shaders elsewhere get their uniforms from node members, so a lint lists every GLSL loop whose bound isn't a literal (tools/bughunt/code_lint.py, rule shader-loop).
