## Repro

A patch with a Set Color node in Palette mode, a palette wired in, and `i paletteOffset 2147483647`.

## Expected

The offset rotates which swatch each element gets, for any int.

## Actual

`(int)index + paletteOffset` overflowed int for any element past 0. That is UB, and the UBSan build aborts there. Release builds wrapped to a negative value, which the `< 0` fix-up turned back into a valid swatch, so nobody saw a wrong colour.

## Fix note

The swatch math moved into `PaletteSwatchIndex()` and is done in 64 bits. For offsets in range the result is the same. A clamp was not used, because any offset is a valid rotation (`clamp_check.py`: 0 saved patches affected either way).
