## Repro

A patch has a Note Echo with `i repeats 20`. The knob allows 1..8, but `Patch::LoadParams` passes ints through. Play overlapping notes into it.

## Expected

Every echoed note-on gets its own note-off.

## Actual

Echo ids are stored under `voiceId * 16 + k`. With `k` above 15, repeat 16 of voice v uses the same key as repeat 0 of voice v+1, and so on. A later voice's note-on overwrites an earlier voice's id, and the earlier voice's note-off then releases the later voice's echo. The overwritten echo is never released.

`transposePerRepeat` is also unbounded. `transposeStep * k` overflows for values near INT_MAX. The result is clamped to 0..127 afterwards, but the overflow is already UB.

## Fix note

`repeats` is clamped to 1..`NoteEchoNode::kMaxRepeats` (8) and `transposePerRepeat` to ±12, which are the knob ranges:
- in `VisitParams`, so the member is in range and the body shows the real value;
- in `PushParams`, for writers that hold the member directly.

A `static_assert` ties `kMaxRepeats` to the key stride of 16. The knobs use the same constants.
