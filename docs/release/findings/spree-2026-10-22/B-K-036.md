## Repro

```
INFINITE_PARAMFUZZ="Audio File,Slicer,PaulStretch,Molder,Granular,Drum Sequencer" Infinite
```

Or load a patch with an Audio File node set to `f volume 1e9` and press play.

## Expected

Each param is held to its knob range, for example volume 0..1, pitch ±24 st, speed 0.25..4.

## Actual

| Node | Value | Result |
|---|---|---|
| Audio File, Slicer, PaulStretch, Molder (level), Granular | volume ±1e9 | peak 5e7 to 5e8, about +170 dBFS |
| Drum Sequencer | any `laneN_stepM` 1e9 | peak 3e8 |
| Audio File | pitch 1e9 | `powf(2, 1e9/12)` is inf, so the read position goes inf and then NaN through `fmod`. `(int64_t)floor(NaN)` is UB (ClipTimeStretch.h:28). In release builds playback goes silent until restart. |
| Slicer | pitch, finetune or speed ±1e9 | float-to-int overflow (UB) |
| Molder | start 1e9 | float-to-int overflow (UB) |

The root cause is the same as B-K-031..035. `Patch::LoadParams` passes any finite float under 2^31 to the node's `VisitParams`, and these nodes stored the value as-is. That covers file load, OSC, RPC, clipboard and presets.

## Fix note

Each node's `VisitParams` clamps to its own knob range (SamplerBodies.cpp, GeometryParams.cpp):
- **Volume, level and step velocity:** 0..1, or 0..2 where the knob goes to 2.
- **Pitch:** ±24 st.
- **Finetune:** ±50 or ±100 c.
- **Speed:** Slicer 0.25..4, Sampler ±2.
- **Start and end:** 0..1.
- **PaulStretch freq shift:** ±1000 Hz.

Sampler was not flagged, but it has the same code, so it gets the same clamp.

Blast radius before the fix:
- **Saved patches:** `clamp_check.py` with all 537 ranges found 0 values in 855 tracked patches that the clamp would change.
- **Other writers:** Arrange's clip pitch goes to the mailbox through `SetClipPitchOverride`, not the member. The grid writes step velocity at 0.05..1. The demo and fixtures use values in range.

## Lesson

The app-launch float sweep logged `Audio File 1e9 ok`. It sets every param of a type to the same value at once, so one param that silences the node (pitch NaN) hides another that makes it hot (volume). It also never started playback. One param per row, on a fixture that plays (`SweepPrepare`), finds both kinds. That is INFINITE_PARAMFUZZ, which covered every audio node in minutes.
