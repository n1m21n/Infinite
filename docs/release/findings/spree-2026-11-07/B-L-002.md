## What happened

EXC_BAD_ACCESS at 0x270 in ed::GetNodePosition ← LoadMaterialMap ← RunPendingMapLoad ← DrawSidePanels. The drain runs after the canvas pass ended, when no editor is current.

## Fix

Save the current editor, `ed::SetCurrentEditor(gEditor)` around the node-position loop, restore after — the same pattern RunAutoLayoutTick and RunFieldGraphUnpackPhase2Tick use.
