## Repro

Patches /tmp/gfuzz1/fail/g1-{581,599,241,222,284,314,426,525,545,552,561}.inf (graph fuzz seed 1). Run 'Infinite --frame <patch> 0 dir/' 6 times: 6 different images, even at frame 0 (differences small: ~7000 px, max 41 levels). Remove the 'mod' lines: identical. Replace Time Machine with a plain wire: identical. Replace the Smoothing modulator by Constant: still different, so it is the binding, not the value. Frame budget (0.1 s yield in the Frames phase) ruled out.

## Notes

Every one of these 11 chains has a modulator binding AND a history node (Time Machine, Trails). Suspects: a bound param forces a recook every frame, and the history node reads the source texture in a state that varies (GPU ordering/async), or the ring write happens before the modulated pass. Not found yet. Real-world impact: a live patch with a modulated param into Time Machine/Trails may look slightly different each launch (cosmetic).
