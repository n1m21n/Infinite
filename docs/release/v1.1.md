## 5. Draft release notes

**3D grows up**
- 3D View follows Blender's workflow: Edit Mode (Tab), Pose mode, X-ray and wireframe overlays, circle select, render passes, mist, cavity, motion blur, camera backgrounds, cylindrical and fisheye lenses, and a Material tab with a live preview ball. Drop a model or any 2D output into the view.
- Rigging: skinned glTF clips and morphs, IK, and a new Armature node that bends any geometry with a bone chain, with weight paint.
- New nodes: Sculpt (brushes fitted to Blender's), Bake (normal map from a sculpt), UV Project, Edit Mesh.
- Render 3D gets a path-trace engine: clearcoat, sheen, glass, depth of field, material maps, opacity. Raster gets area-light soft shadows and a floor bounce. Use the path tracer for scenes that rely on global illumination.
- Cloth now has bending, a collider input and friction; Rigid Bodies use the piece's own axes. Subdivide is Catmull-Clark; Twist on Y turns the same way as X and Z.
- Cloth no longer bypasses (it has two inputs).

**Command line and agents**
- Settings has one-click setup for the terminal and AI agents, including installing the AI skills.

**Fixes**
- Sketch text falls back to CJK fonts. The piano roll plays notes on the loop start after a wrap. Dropdowns close on the first Esc. Wide knob captions and dropdown values end in an ellipsis. Snap-to-grid applies only after a node drag.
