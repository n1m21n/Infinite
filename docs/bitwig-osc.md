# Связка Infinite ↔ Bitwig Studio по OSC (через DrivenByMoss)

Bitwig сам OSC не шлёт — нужно расширение **DrivenByMoss** (режим Open Sound Control). Всё, что нельзя проверить без Bitwig, помечено «не проверено». Подробности и источники: `docs/research/osc-bitwig.md`.

## Что умеет приём в Infinite (ветка `my/osc`, проверено self-test'ом)
- Разбор `#bundle` (вложенные тоже; timetag игнорируется) — DrivenByMoss шлёт именно bundle'ами.
- Типы аргументов: `f`, `i`, `s`, `T/F` (→1/0), `d`, `h`. Приём датаграмм до 64 КБ.
- Несколько нод OSC Receive на одном порту: каждая берёт свой адрес.
- Адрес допускает `*` и `?` (не пересекают `/`), например `/track/*/volume`.
- Параметр **arg index** (по умолчанию 0) — номер аргумента, из которого берётся значение.
- Кнопка **OSC Learn**: следующее числовое сообщение на порту ноды записывает свой адрес в поле address.
- Если порт занят — на ноде красная строка «Cannot listen: …» (повтор попытки раз в ~2 с).
- Ограничение: слушает только 127.0.0.1 (Bitwig на том же компьютере). Строки как значение игнорируются.

## Шаги
1. Скачать DrivenByMoss (https://github.com/git-moss/DrivenByMoss-Documentation), файл `.bwextension` положить в папку Extensions Bitwig, перезапустить Bitwig. *(не проверено, путь зависит от ОС)*
2. Bitwig → Settings → Controllers → Add controller → Moss → **Open Sound Control**. *(не проверено)* Если диалог не появляется без MIDI-устройства — включить IAC Driver в «Настройке Audio MIDI». *(не проверено)*
3. В настройках расширения: **Port to receive on = 8000**, **Host to send to = 127.0.0.1**, **Port to send to = 9000**, Value resolution = Low (128, значения 0..127). *(не проверено; смена хоста/порта требует перезапуска расширения)*
4. В Infinite добавить ноду **OSC Receive** (Utility): port `9000`.
5. Нода №1 — транспорт: address `/play`, arg index 0, low 0, high 1. Значение 1 при Play, 0 при Stop. *(не проверено: тип и частота `/play` на проводе)*
6. Нода №2 — громкость: address `/track/1/volume`, low 0, high 127 (в слайдерах нод верхний предел 127). Вместо ввода руками: нажать **OSC Learn** и подвигать фейдер дорожки в Bitwig — адрес запишется сам. Учтите: Bitwig шлёт много сообщений (`/update`, VU и т.п.); если Learn поймал не то, нажмите ещё раз или впишите адрес вручную. *(не проверено)*
7. Выход ноды перетащить на пин модуляции нужного слайдера. На **привязке** выставить сглаживание (`smoothMs`) ~ 50–100 мс — иначе громкость будет «лесенкой». *(не проверено)*
8. Нажать Play в Bitwig, подвигать фейдер — значение на мониторе ноды должно меняться. *(не проверено)*
9. Проверка без Bitwig (одиночное сообщение; python3 из стандартной библиотеки):
   ```bash
   python3 -c "import socket,struct;s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM);s.sendto(b'/play\0\0\0,f\0\0'+struct.pack('>f',1.0),('127.0.0.1',9000))"
   ```
   Нода с адресом `/play` должна показать 1.0. *(команда не прогонялась руками; тот же путь проверен self-test'ом на bundle и одиночных сообщениях)*

## Пример патча
```
OSC Receive (port 9000, /track/1/volume, low 0, high 127) ──► пин модуляции «gain/opacity» (smooth 80 мс)
OSC Receive (port 9000, /play,            low 0, high 1)   ──► пин модуляции нужного параметра / триггера
```

## Не сделано
- MIDI clock → Transport (темп и фаза от Bitwig). Для синхронизации BPM пока ручной ввод.
- Приём строк (`/beat/str`, `/time/str`) как значений.
