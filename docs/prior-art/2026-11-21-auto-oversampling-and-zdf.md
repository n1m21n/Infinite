## Problem
Has anyone published or shipped a compiler/DSL/graph pass that bounds bandwidth expansion of nonlinear ops per subgraph and picks oversampling factors (or ADAA/BLEP) automatically? Same question for automatic zero-delay-feedback (ZDF) solving in user-patched graphs.

## Patterns across sources
- Every anti-aliasing technique found (oversampling, ADAA, IIR/FIR kernels, Lagrange, stateful extensions) is chosen and wired by hand per nonlinearity. ADAA needs a hand-derived antiderivative (or LUT-integrated one, Gabrielli DAFx25, search-seen) per shaper.
- The only compile-time analysis of DSP value ranges I found is Faust's interval arithmetic (inputs [-1,1], sliders min/max, per-op interval rules). It sizes delay lines, guards table indices and picks fixed-point formats (Herrou, de Dinechin, Letz, Orlarey, Volkova, arXiv 2403.06527, Mar 2024, first page OPENED; interval docs seen only in search at https://faustdoc.grame.fr/manual/debugging/). Recursive signals degrade to [-inf, inf] (search summary). It tracks amplitude, not bandwidth.
- Rate-changing containers exist (Faust OD/US/DS, HISE scriptnode oversampler container, JUCE dsp::Oversampling, fundsp oversample.rs) and are all placed by the user.
- ADAA and oversampling are combined in practice ("low order oversampling" in Parker 2016 abstract).
- Zero-delay loops: Faust lacks a solver; the list consensus is to unroll fixed-point iterations N times (Muller, 23 Aug 2018, OPENED). Linear loops are pre-solved algebraically; nonlinear ones use Newton or non-iterative schemes (Ando, Bozzo, Fontana DAFx25 paper 6, OPENED abstract).
- Nearest outside-audio analogue for "propagate bandlimit through a program automatically": Yang and Barnes, Eurographics 2018 (CGF 37(2) 443-454), compiler framework that smooths shader programs using mean/variance statistics and searches approximation choices. Graphics, not audio; SEEN IN SEARCH ONLY (https://arxiv.org/pdf/1706.01208).

## Verdict (details in final message)
- Per-subgraph automatic oversampling chosen by static analysis of nonlinearity order: not found anywhere. Pieces exist (items 1, 2, 3, 7, Faust intervals, Yang and Barnes); nobody has joined them. Absence is not proof (see "Searched, found nothing").
- Automatic ZDF in user-patched graphs: not found as a product of a graph compiler. Pieces: Zavalishin TPT recipe (hand), Holters state-space ADAA, WDF code generators (item 8, VIOLA, Yeh 2010), Faust unrolling hack.
