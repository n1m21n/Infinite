# Infinite: press kit (v1.1.0)

**Infinite** is a free, open-source audiovisual workstation by Naman Soni (n1m21n).
Visuals, music and code live on one node canvas. macOS, Windows (x64, ARM64), Linux.
Languages: English, Spanish, German, Chinese, Japanese, Russian.

## In one line
A DAW for you: sound, picture, 3D and code patched together on one canvas, free and open source.

## Key facts
- 347 node types; every cable carries audio, notes, pictures, 3D or control signals
- Any source can modulate any parameter (synth knob, shader, 3D transform, plugin parameter)
- Sound: Analog, FM, Wavetable, Piano, Wind, Granular, Sampler, Drum Sequencer, effects rack, AU + VST3 hosting
- Generate Samples: loops rendered from Infinite's own instruments, saved as a recipe
- Visuals: GPU compositing, 32 blend modes, Syphon / Spout / NDI, procedural 3D, PBR, particles, cloth
- Session clip launcher, Timeline, Piano Roll, Sample Studio, MIDI in/out, audio + video render
- Field: Infinite's own programming language for writing what a node does
- Patches are text files and render headless to image, video or audio from the command line
- 15 starter patches + a self-playing Showcase patch
- Licence: MIT / GPLv3. No account, no paid tier.
