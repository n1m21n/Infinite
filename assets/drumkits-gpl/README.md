# SLOOP drum kits (Infinite-Turbo full build only)

The 37 drum kits of SLOOP (github.com/isod89/sloop-fm1, fork of Felucca by Leo Kuroshita), rendered to
samples by running SLOOP's own drum engine (firmware/src/drums.c, drum_synth.c, kit data from
tools/gen_drumkits.py) one hit per sound at 44.1 kHz. The five sampled kits (ACOUSTIC .. DUST) are SLOOP's
processing of CC0 VCSL recordings; the other 32 are its synthesised kits.

Treated as GPL-3.0 material: shipped only with the full build (CMake INFINITE_ENABLE_GPL=ON), never
in the MIT release. File names follow the Drum Sequencer lanes (01-kick .. 08-bell) plus eight extra
sounds (kick 2, rim, pedal hat, snare 2, crash, ride, shaker, conga).
