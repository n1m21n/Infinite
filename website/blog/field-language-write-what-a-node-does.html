Field: write a short kernel and let the node decide where it runs

Field is the language built into Infinite. One kernel can become a shader, a geometry deformer or an audio effect, depending on the node it lives in.

By Naman Soni

on this page
  1. One idea: a kernel run once per element
  2. The Field nodes
  3. Knobs that become pins
  4. Why a language, not another plugin format

Most nodes do one fixed thing. A Blur node blurs and a Delay node delays. Creative work often needs something in between, so Infinite includes Field, a kernel language for shaders, geometry and audio: a small language for writing what a node does.

One idea: a kernel run once per element

A Field node runs your kernel once for every element of its domain, forever. The domain is chosen by the node, not by you:

col = vec3(uv.x, uv.y, 0.5)              // once per pixel, on the GPU: a shader
P.y += sin(P.x * 4.0 + t) * 0.2          // once per point in a mesh: a geometry deformer
out = in * gain                          // once per audio sample: a DSP effect

You never declare a backend. The same way of thinking covers pictures, shapes and sound.

The Field nodes

NodeDomainWhat it does
Field PixelpixelPer-pixel kernel compiled to GLSL, with state cells for feedback
Field ModifierelementPer-vertex kernel over existing geometry
Field PrimitiveelementGenerates point geometry such as spirals, lattices and torus knots
Field EffectsamplePer-sample audio effect with in, out, state and param
Field SynthsampleA polyphonic synth voice driven by freq and gate
Field NotessampleSends notes with note(pitch, vel, len) and reads the transport
Field GraphgraphRuns at edit time and builds real nodes and cables

Knobs that become pins

A kernel can declare parameters in its own code, and each one becomes a real input on the node:

param float cutoff = 0.25 [0.01, 0.99]
state float z = 0
z += (in - z) * cutoff
out = z

That is a one-pole low-pass filter. The cutoff pin can be wired to an LFO, a MIDI knob or the output of an Audio Analyze node like any other control, and it survives save and load.

Why a language, not another plugin format

A kernel is short enough to read in one go and to share as a text file. The Library has a growing set of free Field devices to start from, and the language reference is available as a PDF manual.
