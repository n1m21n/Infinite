Tracking

Install

In Infinite, open Settings → Extensions and press Install next to Tracking. It downloads, checks and installs while the app runs, the same way live updates do. No restart. When a newer version is published, the same row shows Update the next time you open the tab.

Offline? Download your platform's pack and use Install from file: macOSWindows x64Windows ARM64Linux x86_64
