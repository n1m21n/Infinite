Infinite for artists

Build images that move. Layer shapes, video and 3D, smear them with trails, and let a sound or an LFO move any knob. No code to start; code when you want it.

What you get

32 blend modes

Stack any picture on any other: images, folders of stills, hardware-accelerated video, camera, paint and noise ramps.

3D with real materials

Procedural geometry, lights and a Render 3D node, so a shape can turn, instance and throw shadows in real time.

Write a picture as a formula

Field Pixel and the live GLSL editor turn a few lines into a shader. Presets show how, and every value can be modulated.
