Install

  1. Download a .field file.
  2. Add a Field Pixel node and press Import in its Devices row.
  3. Pick the file. The device loads into the node, and you can save it to your own Devices list.

Filters and generators

Filters read an image you patch in (the small inset in a preview is the source). Generators draw on their own and need no input.

Free for now

Everything here is free while the library grows. Each device is plain Field code you can open and edit.
