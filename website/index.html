How Does It Work?

Recipe 01

Making Live Audio-Reactive Visuals

An Audio Analyze node splits sound into 8 frequency bands. Connecting a high-frequency band to a Ripple Filter causes live video to distort in exact sync with percussion.

Audio In → Audio Analyze → Ripple Filter → Visual Output
Recipe 02

Turning Any Sound into Ambient Clouds

Drop any sound file into PaulStretch to stretch time up to 50x without changing pitch. Feeding the wash through an Algorithmic Reverb creates endless atmospheric textures.

Audio File → PaulStretch → Reverb & Delay → Audio Out
Recipe 03

Live Shader Grading & Kaleidoscope FX

Wire image textures into Color Adjustment, modulate tones using an XY Motion Pad, and blend through Kaleidoscope and optical Bloom.

Texture / Image → Color Adjust → XY Motion Pad → Kaleidoscope & Bloom
Recipe 04

Dual-Engine Wavetable Sound Design

Stack dual morphing oscillators in Wavetable Synth with 3 envelope generators, route through a resonant Stereo Filter, and immerse in Chorus, Delay & Reverb.

Wavetable Synth → 3x ADSR Envelopes → Stereo Filter → Chorus & Reverb
Recipe 05

Spectrogram Synthesis & 3D Texture Mapping

Synthesize image pixels directly into 128 audio harmonics with Spectrogram Synth while simultaneously projecting the texture onto a rotating 3D geometry cube in Render 3D.

Artwork Source → Spectrogram Synth (128p) → Render 3D Viewport

First-Time Setup

Opening Infinite on macOS in 3 Steps

Because Infinite is a free community open-source project and built as an ad-hoc signed app, macOS Gatekeeper may show a one-time security confirmation on your first launch. Here is how to open it:

1

Double-Click App

Drag Infinite.app to your Applications folder and double-click. macOS will state it is from an unverified developer.

2

System Settings

Open System Settings → Privacy & Security, scroll down to the Security section, and click "Open Anyway".

3

Terminal Shortcut (Optional)

Or remove the browser quarantine flag instantly with one line in Terminal:

xattr -dr com.apple.quarantine /Applications/Infinite.app
First-Time Setup

Opening Infinite on Windows in 3 Steps

The Windows build is a portable folder — no installer, nothing written to your registry. It's unsigned, so Windows shows a one-time warning on first launch. Most PCs need the Intel / AMD (x64) build from the download button; on a Snapdragon X or other ARM laptop, take the ARM64 build instead — check Settings → System → About → System type if unsure. Here's how to open it:

1

Unblock the ZIP

Right-click the downloaded ZIP, choose Properties, tick Unblock at the bottom, then OK. Now extract it. Doing this before extracting saves you from being asked about every file inside.

2

Run Anyway

Extract anywhere you like and run Infinite.exe. If Microsoft Defender SmartScreen appears, click More info, then Run anyway. Keep the whole folder together — Infinite.exe loads its assets from alongside itself.

3

Opening Patches

Patches save as .infinite files. Windows will not know what they are until you tell it once: right-click a patch, choose Open with → Choose another app, pick Infinite.exe and tick Always. Dragging a patch onto the canvas works right away, with no setup.
