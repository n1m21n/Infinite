first launch

Infinite is free and unsigned, so your OS asks once. Here is the one-time step for each.

Infinite is an ad-hoc signed community app, so macOS Gatekeeper asks for a one-time confirmation on first launch.

  1. 1

    Double-click the app

    Drag Infinite.app to Applications and double-click it. macOS says it is from an unverified developer.

  2. 2

    Open anyway

    Open System Settings, Privacy & Security, scroll to Security, and click Open Anyway.

  3. 3

    Or one line in Terminal

    Remove the quarantine flag instantly:

    xattr -dr com.apple.quarantine /Applications/Infinite.app

The Windows build is a portable folder: no installer, nothing written to your registry. It is unsigned, so Windows warns once on first launch. Most PCs need the Intel / AMD (x64) build. On a Snapdragon X or other ARM laptop take the ARM64 build instead (check Settings, System, About, System type if unsure).

  1. 1

    Unblock the ZIP

    Right-click the ZIP, choose Properties, tick Unblock, then OK. Then extract it. Doing this first saves you a prompt for every file inside.

  2. 2

    Run anyway

    Run Infinite.exe. If SmartScreen appears, click More info, then Run anyway. Keep the folder together: Infinite.exe loads its assets from beside itself.

  3. 3

    Opening patches

    Patches save as .infinite files. Right-click one, Open with, Choose another app, pick Infinite.exe and tick Always. Dragging a patch onto the canvas works with no setup.

Infinite ships as one portable AppImage. It bundles the static AppImage runtime, so you do not need libfuse2. Needs x86_64, glibc 2.35 or newer (Ubuntu 22.04+, Debian 12+, Fedora 38+ or similar) and OpenGL 3.2 via X11 or XWayland.

  1. 1

    Make it executable

    Download Infinite-x86_64.AppImage, then:

    chmod +x Infinite-x86_64.AppImage
  2. 2

    Run it

    Double-click it, or run it from a terminal. Inside a container, or with no /dev/fuse, extract and run instead:

    ./Infinite-x86_64.AppImage --appimage-extract-and-run
