Infinite for developers and agents

Every patch is a text file, and the app can render it with no window open. Use the command line, call it from Python, or hand the same tools to an AI agent over MCP.

Command line

Validate a patch, print the graph that was built, then render stills, video or an audio report.

Infinite --validate hello.inf
Infinite --explain hello.inf
Infinite --frame hello.inf 0,1,2 pics/ --contact-sheet sheet.png
Infinite --render hello.inf hello.mp4 --duration 4 --fps 30
Infinite --audio-summary hello.inf hello.json

Headless guide (PDF) covers every flag and exit code.

Python SDK

A thin wrapper over the same command line. Run it from a checkout of the repository.

git clone https://github.com/n1m21n/Infinite
cd Infinite/tools/python_sdk
python3
>>> import infinite
>>> infinite.field_synth("state float phase = 0\nphase = (phase + freq / sr) % 1.0\nout = sin(6.28318 * phase) * 0.4 * gate", out_wav="synth.wav", duration=3)

Functions: render_video, field_synth, field_effect, field_notes, sketch_3d, field_primitive, field_modifier, validate. Source and README.

MCP server

Nine tools over stdio for Claude Desktop, Cursor and other MCP clients. Add this to the client's config, with the path to your checkout.

{
  "mcpServers": {
    "infinite": {
      "command": "python3",
      "args": ["/path/to/Infinite/tools/mcp/infinite_mcp.py"]
    }
  }
}

Source and README.

The nine MCP tools

ToolWhat it does
infinite_render_videoSynthesise audio and render an MP4 from GLSL or a 2D sketch
infinite_render_frameRender one PNG from a shader, sketch or .inf patch
infinite_validate_patchCheck a .inf file and report every problem
infinite_field_synthPer-sample Field synth to a WAV
infinite_field_effectRun audio through a Field effect kernel
infinite_field_notesAlgorithmic notes, such as Euclidean rhythms
infinite_sketch_3dProcedural 3D meshes from a JavaScript sketch
infinite_field_primitiveParametric 3D surfaces from uv to P, N, Cd
infinite_field_modifierDeform and shade a mesh with a Field modifier

What you need

  • The Infinite app installed. The SDK and the MCP server find it through the INFINITE_BIN environment variable, /Applications/Infinite.app, a build folder in the checkout, or your PATH. On Windows and Linux, set INFINITE_BIN to the path of Infinite.exe or Infinite.
  • Python 3.8 or newer. Nothing else to install: the SDK has no dependencies.
  • The Python package is not on PyPI yet, so pip install will not find it. Use the checkout.
  • Hardware inputs, such as a microphone or camera, are refused in headless mode.

For web builders

Putting a visual on a page needs no install. Embeds has 11 audio-reactive widgets and one iframe to copy for each. Agents can read the whole site as plain text in llms.txt, and the repository carries an agent guide.
