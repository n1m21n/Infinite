3D node

Tetrahedron

A four-faced platonic solid: the simplest 3D shape that can enclose space, made of four triangles.

Download the patchRead it in the Field Guide

What it does

Tetrahedron is a 3D node: it builds, changes or lights geometry that Render 3D turns into a picture. It takes picture in and gives 3D shape out.

Try it

Put one under a Wireframe node for a crisp geometric diagram look.

Tetrahedron→Wireframe→Render 3D

Inputs and outputs

Inputs

  • picture texture

Outputs

  • 3D shape out

Example patch

This patch wires Tetrahedron to what it needs and shows the result. Download it, then use File, Open in Infinite, or read it here: it is plain text.

infinite-patch 1
rev 2
# Tetrahedron: a starting patch for the Tetrahedron node
node 1 3D Tetrahedron
  id node
  pos 520 300
end
node 2 Source Ramp
  id in0
  pos 0 300
end
node 3 3D Render 3D
  id view
  pos 1080 300
end
node 4 Utility Output
  id out
  pos 1640 300
end
cable node 0 in0
geo view 0 node
cable out 0 view

your turn
