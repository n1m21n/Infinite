Message, or @ for a node

An illustration drawn from the real chat. Node names are examples.

It edits the real patch

Changes land on the canvas you have open, live. The chat calls the same commands as the infinite command line, so the two cannot drift apart.

Every name is a link

Nodes and parameters in a reply are chips. Click one and the canvas selects it, frames it and flashes the control.

No new account

You sign in to the agent with the provider, in your browser. Infinite has no login of its own and no servers in the middle.

What it does

  • Builds and changes patches. Ask for a sound, a look or a wiring change in plain words. The agent adds nodes, sets parameters and connects cables in your open window.
  • Runs short commands itself. Sentences like @cube set size to 2 or connect @a to @b run at once, without waiting for a model.
  • Shows what it made. Pictures, audio files and code blocks in a reply appear in the chat. Pictures open full size on a click.
  • Explains and checks. /explain describes your patch, /check validates it and its code, and /docs answers from the manuals, so a question about Field or a node never needs a web search.
  • Has slash commands. /help lists them. @claude, @chatgpt and @gemini choose who answers, /new starts a fresh chat and /undo takes back the last change.
  • Takes files and pictures. Press + or paste from the clipboard. Attached pictures open full size on a click.
  • Lists every change. Each reply carries only this turn's changes, with live knobs for the values it set, links to the node or parameter, and Undo. A generated sample can be opened in a Sampler.
  • Floats where you need it. Chat, Viewport, Modulation Matrix and Performance can each pop out into their own window.
  • Keeps your history. Chats are saved on your computer, searchable, and cleared with one button in Settings.

How it works

  1. 1

    You type a sentence

    The composer knows which slot comes next, so it suggests nodes after @, that node's parameters after it, and valid values after to.

  2. 2

    Infinite reads it first

    A short grammar checks whether the line is an exact edit. If it parses fully, it runs directly (the direct route). Anything else goes to your agent (the agent route).

  3. 3

    Your agent runs on your computer

    Claude Code, Codex or Antigravity starts as a local process, in the folder you choose, with a short briefing on how to edit this window. It talks to its own provider over your account.

  4. 4

    Every write goes through one gate

    Agent edits are made with the same commands as the infinite command line, inside the window you have open, so a bad edit is refused by the engine and not half-applied.

  5. 5

    You see exactly what changed

    A change card lists what moved and keeps an Undo. A direct edit also shows the command line it equals. Tool calls fold into one quiet row you can open.

Infinite does not speed up a provider's model, and the page does not pretend to. It removes the waiting you do not need: exact edits never reach a model, and the agent route starts with the window's contents in hand, so the agent does not spend turns finding out what is on the canvas.

How it understands

The chat lives inside the app, so it does not guess from a screenshot. It keeps a live catalog of the window and refreshes it on every change to the graph.

  • Nodes. Titles, types and positions, so @oscillator means the node you mean, even when two share a title.
  • Parameters. For each node: every control, its label, range, step and enum values, and whether it can be modulated.
  • References. A name you type becomes an exact reference, so an edit lands on the right node and the right control.
  • Plain replies. Agents are asked to write nodes as links, changes as old → new, and to end with a short list of what changed.

  • Sign-in happens in your browser, on the provider's own page. Infinite never asks for, sees or stores your password.
  • Your plan and your limits. Usage counts against your own subscription or key, the same as using the agent anywhere else.
  • One setup card. A first run installs what is missing, connects the agent to the window and signs you in, all from the chat.
  • One model picker. The chat shows the models of the agent that is answering, and Settings holds a default for each of the three. Each reply shows its token count, and Settings shows usage per agent with a Reset.
  • Add more than one. When two agents work at once, the chat shows who is doing what.

You stay in control

  • Undo everything. Every change card carries an Undo, and a direct line is one undo step even when it joins several clauses with and.
  • Refusals are shown. If an agent tries something it is not allowed to do, the chat says so in plain words instead of failing silently.
  • You choose the folder. The agent works in the folder you set in Settings, or the open patch's folder.
  • Local history. Saved chats stay on your computer, and Settings shows how many there are with a Clear all button.
  • Prefer a terminal? The terminal button opens a real terminal on the right, beside the chat.

Get started

  1. Download Infinite and open a patch.
  2. Open the chat panel, choose Claude, ChatGPT or Gemini, and press Connect. Finish signing in in the browser.
  3. Type @ and pick a node, then say what you want.

Building tools of your own? The developers page covers the command line, Python SDK and MCP server that the chat is built on.
